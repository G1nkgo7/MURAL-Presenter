# MURAL Presenter v0.1 archive

This directory freezes the retired v0.1 Skill/Harness pair for historical
inspection only:

- `skills/mural-presenter-v0.1/`
- `harnesses/mural-presenter-v0.1/`

v0.1 is not registered by the WebUI and must not be selected for new,
revision, or resumed jobs. Historical decks 13 and 14 keep their rendered
artifacts, but their stored absolute runtime paths are intentionally not
rewritten. Restore the pair to its original top-level paths from Git history
only when an explicit forensic replay is required.

The final v0.1 player `fontsReady` compatibility change was migrated to every
active v0.2 Single/Grouped language edition before archival.
