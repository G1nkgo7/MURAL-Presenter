# README capability icons

Three existing manuscript illustrations identify grounded content, adaptive responsibility and
visual revision. The root English and Chinese READMEs display them alongside text labels.

| Icon | Manuscript source | Use |
| --- | --- | --- |
| [Research](research.png) | `figure_sources/transparent_icons/research.png` | Grounded content |
| [Group Owner](group-owner.png) | `figure_sources/transparent_icons/group.png` | Adaptive responsibility |
| [Inspection](inspect.png) | `figure_sources/transparent_icons/objects/inspect.png` | Visual revision |

The original transparent PNGs are copied without redrawing, cropping or re-encoding.
[manifest.json](manifest.json) records their sources and SHA-256 hashes. Image display size is
set in the README; the originals retain their resolution. Decorative image alt text is empty
because adjacent text carries the meaning. These are manuscript illustrations, not new logos.

中文：沿用论文中的三个透明图标，不重新绘制；小图标辅助识别功能，不替代文字说明。
