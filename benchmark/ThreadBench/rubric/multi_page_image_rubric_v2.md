# 多页演示文稿 Deck-Level 通用图像评测 Rubric v2

## 1. 设计结论

本 Rubric 保留 5 个压缩后的 Deck-level 维度，采用严格的 `0–5` 六档整数分。六档并不过多：`0` 专门表示未实现或根本失效，`1–5` 分别表示严重不足、部分实现、基本合格、良好和标杆。维度禁止小数，最终分为五个维度的算术平均值。

- `3` 是完整可用的最低合格档，不是高分。
- `4` 要求不存在重大问题，不能作为默认分。
- `5` 必须全页核查、证据充分且没有实质缺陷。
- 没有实现、核心目标完全缺失或根本失效时直接为 `0`。

## 2. 适用范围与有效性

只评价任务上下文与全 Deck 渲染图中可观察的内容和美学质量，不评价 HTML、DOM、CSS、离线运行、加载、控制台、导航或隐藏状态等工程属性。

有完整可观察的 Deck，但某个维度未实现或根本失效时，该维度记 `0`；只有输入本身不足以评价整套 Deck 时才记 `invalid`，不填写维度分和最终分。

## 3. 统一评分尺度

| 分数 | 等级 | 严格定义 |
|---:|---|---|
| `0` | 未实现/根本失效 | 未实现或根本失效。该维度没有形成可用结果，核心目标完全未成立，或存在足以使该维度整体作废的致命问题。 |
| `1` | 严重不足 | 严重不足。能看出最低限度尝试，但多数核心要求未完成，主要问题普遍且严重，不能用于正常交付。 |
| `2` | 部分实现 | 部分实现。基本方向或局部结构成立，但仍有多个重大缺口、错误或失衡，需要大幅修改后才能可靠使用。 |
| `3` | 基本合格 | 基本合格。核心要求已完整实现，主体可用，但仍存在清楚可见的实质问题；这是最低完整交付档，不代表高质量。 |
| `4` | 良好 | 良好。要求得到充分实现，整体专业稳定，仅有少量局部、非核心的小问题，不影响主要理解和使用。 |
| `5` | 标杆 | 标杆。实现完整、准确、成熟且高度有意，没有可观察的实质缺陷；只允许极少量不影响任何核心页面、章节或结论的可忽略瑕疵。 |

### 评分纪律

- 每个维度只能输出 0、1、2、3、4、5 中的一个整数；不得输出小数、区间分、百分制或将置信度混入分数。
- 采用“最高完全满足档”原则：从高到低检查锚点，只有某档的全部核心条件都成立时才能给该档；不满足时必须降至下一档。
- 先检查 0 分触发条件。未实现、核心目标完全缺失或根本失效时直接为 0，不得因为局部亮点补分。
- 3 分是完整可用的最低合格线。核心要求尚未全部实现时最高为 2；只有尝试但整体不可交付时为 1。
- 4 分要求不存在重大问题；只要仍有一个影响核心章节、核心结论或关键视觉节点的实质问题，最高为 3。
- 5 分不是“看起来很好”。必须完成全页和全章节核查、找不到实质缺陷，并能提供覆盖整套 Deck 的正面证据。
- 证据不足、页序不全、只抽查少量页面或无法排除关键矛盾时，不得给 4 或 5；若因此无法确认核心要求完成，最高为 2。
- 长 Deck 必须全页巡检并覆盖每个核心章节；不得仅用首尾页或少数代表页推断整套质量。
- 每个维度必须给出页码、相邻页对、章节范围或故事板位置等可复核证据；低于 5 分必须指出导致降分的具体缺陷。
- 不因页数多、制作成本高或局部亮点而补偿核心缺陷；五个维度独立评分。

## 4. 五个评分维度

| 编号 | 模块 | 维度 | 关键性 | 核心问题 |
|---|---|---|---|---|
| C1 | Content | 任务完成度与结构覆盖 | 关键 | 整套 Deck 是否准确回应目标、受众、用途和显式约束，并以合理章节与篇幅覆盖完成任务所需的核心内容。 |
| C2 | Content | 叙事架构、顺序与节奏 | 标准 | 页面和章节是否形成可跟随的主线；结论是否获得必要铺垫与回收；跨页顺序、信息切分、密度和冗余是否共同服务理解。 |
| C3 | Content | 准确性、证据与跨页一致性 | 关键 | 关键事实、结论、术语、数字、单位、日期、图表和引用是否准确、有依据，并在摘要、正文、图表与附录之间保持一致。 |
| A1 | Aesthetic | 全局视觉系统、可读性与执行稳定性 | 关键 | 全 Deck 的字体、色彩、网格、间距、组件、图表、图标和图片语言是否形成稳定系统，并在所有核心页面保持清楚、完整、专业的视觉执行。 |
| A2 | Aesthetic | 视觉叙事、节奏与定位 | 标准 | 页面序列是否通过有目的的视觉变化、重复、章节线索和图文映射强化主线，使读者理解当前位置、进度、重点和章节关系。 |

### C1 任务完成度与结构覆盖

**定义：** 整套 Deck 是否准确回应目标、受众、用途和显式约束，并以合理章节与篇幅覆盖完成任务所需的核心内容。

**评价方式：** 对照任务说明、全 Deck 故事板、章节与页面角色及要求清单，检查主题、目标受众、用途、核心章节、信息深度和篇幅分配是否一致；区分必要展开与为了增加页数而产生的凑页。

**主要证据：** `instruction_or_brief`、`full_deck_storyboard`、`section_and_slide_roles`、`requirement_checklist`

| 分数 | 严格判定标准 |
|---:|---|
| `0` | 没有形成与任务相符的完整 Deck；主题、用途或受众根本错误；实现任务所必需的核心章节、关键交付物或路径完全缺失，使整套无法完成目标。局部出现相关关键词或精美页面不能避免 0 分。 |
| `1` | 只有表层回应或零散相关页面；多数核心章节、显式约束或受众需求未完成，结构近似占位提纲，大量内容偏题、空洞或凑页，不能作为目标场景下的正常交付。 |
| `2` | 基本方向正确并完成部分主要章节，但仍缺少一个或多个重要要求，或存在明显受众/深度错位、章节比例严重失衡和多处凑页；需要大幅补写、删改或重组才能完整交付。 |
| `3` | 核心目标、主要章节和关键交付要求均已实现，整套可以用于目标场景；但仍有清楚可见的实质遗漏、深度不足、章节失衡、受众适配偏差或冗余页面，完成度合格但不够充分。 |
| `4` | 显式约束和核心隐含需求得到充分覆盖，结构、深度、受众和篇幅分配适合用途；没有重大遗漏、明显偏题或系统性凑页，仅有少量非核心内容可进一步精简或补充。 |
| `5` | 所有显式与核心隐含需求均被精确、完整且有洞察地满足；章节取舍、深度、受众适配和篇幅比例高度有意，每个章节和页面都有不可替代的作用，无实质遗漏、偏题、失衡或凑页。 |

**硬门槛：**

- 任务必需的核心章节、关键交付物或路径完全缺失时为 0。
- 任一重要要求尚未实现，或 Deck 仍需大幅补写才能完整交付时最高为 2。
- 仍有影响核心用途的实质遗漏或受众错位时最高为 3。

### C2 叙事架构、顺序与节奏

**定义：** 页面和章节是否形成可跟随的主线；结论是否获得必要铺垫与回收；跨页顺序、信息切分、密度和冗余是否共同服务理解。

**评价方式：** 结合故事板、提纲、相邻页对、密度/重复扫描和顺序扰动测试，判断每页角色、章节职责、前后关系、转场、信息切分与视觉/内容节奏是否有意，且是否减少回跳、突跳、过载、空泛与重复。

**主要证据：** `full_deck_storyboard`、`outline`、`adjacent_slide_pairs`、`density_and_duplicate_scan`、`order_perturbation_test`

| 分数 | 严格判定标准 |
|---:|---|
| `0` | 没有可识别的主线或页面序列近似随机；关键因果、前后关系或结论支撑根本断裂，读者无法沿正常顺序理解主要内容。叙事架构实际未实现。 |
| `1` | 能辨认少量章节或局部关系，但主线频繁中断，页面角色混乱，关键结论缺少铺垫，多处突跳、回退、重复、过载或空泛，整体无法顺畅跟随。 |
| `2` | 存在基本提纲和大体顺序，部分章节内部可跟随；但有多个重要断层、弱转场、铺垫不足、顺序不佳、重复页或连续密度问题，明显需要重排、合并或拆分。 |
| `3` | 全局主线和核心论证可以跟随，主要章节职责及基本顺序成立；但仍有若干实质性的局部断层、弱转场、章节失衡、重复或节奏波动，影响流畅性但未破坏整体理解。 |
| `4` | 主线清楚，关键结论有充分铺垫与回收，页面角色、相邻页关系、章节转场和信息密度整体成熟；不存在重大叙事或节奏问题，仅有少量局部顺序或拆分可优化。 |
| `5` | 叙事架构经济有力且高度适合场景；每页角色必要，每次转场都有明确理由，结论、证据、回收和章节节奏紧密协同；任意实质重排或删除都会降低理解，无断层、冗余或失衡。 |

**硬门槛：**

- 没有可识别主线或正常顺序无法理解主要内容时为 0。
- 存在多个需要重排核心章节才能修复的重大断层时最高为 2。
- 任一核心结论缺少必要支撑或存在明显顺序断层时最高为 3。

### C3 准确性、证据与跨页一致性

**定义：** 关键事实、结论、术语、数字、单位、日期、图表和引用是否准确、有依据，并在摘要、正文、图表与附录之间保持一致。

**评价方式：** 对照源材料或任务上下文、关键 claim 清单、数字/单位/日期抽取和图表/表格/引用，检查核心结论是否有支持，数据口径是否清楚，同一实体与术语是否稳定，差异是否被明确解释。无数值型内容时仍需评价事实、术语、结论和示例的一致性。

**主要证据：** `source_material_or_instruction`、`claim_manifest`、`extracted_facts_numbers_units_and_dates`、`charts_tables_and_citations`、`summary_body_appendix_cross_check`

| 分数 | 严格判定标准 |
|---:|---|
| `0` | 准确性或证据体系根本失效：存在伪造来源、伪造关键数据、关键事实严重错误、核心结论与证据相反，或跨页矛盾足以改变主要判断。该维度没有形成可信结果。 |
| `1` | 多个关键主张缺乏支持，或存在多处严重事实、数字、单位、日期、术语和图表冲突；引用不可追溯或明显不可靠，读者无法信任主要结论。 |
| `2` | 核心方向大体可信，但仍有若干重要主张支持不足、口径不清、跨页冲突或引用缺口；部分错误可能影响判断，需要系统核对和修订后才能可靠使用。 |
| `3` | 核心结论可信，未发现伪造或足以推翻主线的关键错误；主要数据和术语大体一致，但仍存在清楚可见的局部证据不足、口径解释缺失、数字/标签不一致或引用不完整。 |
| `4` | 关键主张均有充分支持，事实、数字、单位、日期、术语、图表与引用在全 Deck 中稳定一致；仅有少量不改变结论的舍入、格式、标签或非核心引用问题。 |
| `5` | 所有关键主张均可追溯到可靠证据；事实、数据、单位、日期、术语、摘要、正文、图表和附录完全协调，数据谱系与口径差异被主动解释，无事实错误、矛盾或证据缺口。 |

**硬门槛：**

- 任一伪造来源、伪造关键数据或足以改变核心结论的矛盾为 0。
- 仍有可能影响主要判断的重要事实或证据问题时最高为 2。
- 任一关键主张缺少充分支持，或存在实质跨页不一致时最高为 3。

### A1 全局视觉系统、可读性与执行稳定性

**定义：** 全 Deck 的字体、色彩、网格、间距、组件、图表、图标和图片语言是否形成稳定系统，并在所有核心页面保持清楚、完整、专业的视觉执行。

**评价方式：** 从故事板和全页巡检判断视觉 token、版式规则、组件/图表/图像语言与可读性是否稳定；区分有意的章节变化与无意的模板碰撞、风格漂移、裁切、遮挡、溢出、低对比和重复性渲染缺陷。

**主要证据：** `full_deck_storyboard`、`typography_color_grid_and_spacing_scan`、`component_chart_icon_and_image_inventory`、`clipping_overlap_and_readability_scan`

| 分数 | 严格判定标准 |
|---:|---|
| `0` | 没有形成可用的跨页视觉系统，或核心章节出现系统性不可读、严重裁切/遮挡/溢出、组件崩坏和模板冲突，使整套无法正常观看或专业使用。视觉实现根本失效。 |
| `1` | 只有最低限度主题痕迹；大量页面存在明显模板碰撞、字号/颜色/网格漂移、低可读性或渲染缺陷，多个核心页面需要重做，整体呈现严重不稳定或接近半成品。 |
| `2` | 能识别基本视觉方向，部分页面可用；但跨章节风格与组件反复漂移，多张关键页存在明显可读性、裁切、遮挡、溢出或完成度问题，需要系统性视觉重构。 |
| `3` | 全 Deck 基本属于同一视觉系统，核心页面总体可读且完整，可以正常展示；但仍有清楚可见的实质性字体、颜色、边距、网格、组件或图像风格漂移，以及少数关键页执行问题。 |
| `4` | 视觉系统成熟、专业且跨页稳定，章节变化有明确目的，所有核心页清楚完整；没有重大可读性或执行缺陷，仅有少量局部 token、对齐、组件或图像处理问题。 |
| `5` | 从缩略图到逐页细节均呈现统一、精确、成熟且有辨识度的视觉系统；变化完全服务结构，所有页面可读、完整、精致，组件与媒体语言高度协调，无可观察的实质视觉缺陷。 |

**硬门槛：**

- 核心章节系统性不可读或视觉实现整体无法使用时为 0。
- 多张关键页需要重做，或跨章节存在反复的严重视觉/渲染问题时最高为 2。
- 任一核心页仍有影响使用的严重不可读、主体裁切、遮挡或半成品状态时最高为 3。

### A2 视觉叙事、节奏与定位

**定义：** 页面序列是否通过有目的的视觉变化、重复、章节线索和图文映射强化主线，使读者理解当前位置、进度、重点和章节关系。

**评价方式：** 检查故事板、视觉类型序列、章节标记/重复锚点及关键结论与视觉的对应关系，判断变化与统一是否平衡，视觉是否承担解释或强调作用，以及长 Deck 是否避免机械套版、极端单调和无规则跳变。无页码本身不构成扣分。

**主要证据：** `full_deck_storyboard`、`visual_type_sequence`、`chapter_markers_and_repeated_anchors`、`key_message_to_visual_mapping`

| 分数 | 严格判定标准 |
|---:|---|
| `0` | 没有形成可理解的视觉序列；机械重复或无规则跳变严重到读者无法识别章节、位置和重点，关键视觉与结论脱节或误导。视觉叙事实际未实现。 |
| `1` | 仅有零散章节标记或视觉变化；长段页面极端单调或频繁突变，重点缺乏强调，图表/图片多为装饰，读者经常失去位置和推进关系。 |
| `2` | 基本章节可以识别，局部存在有效视觉变化；但仍有多个长段机械套版、弱章节边界、无规律跳变或图文匹配不足，视觉未能稳定支持叙事推进。 |
| `3` | 读者基本能够识别章节、位置和重点，主要视觉类型与内容任务大体匹配；但仍有清楚可见的单调区段、弱转场、节奏平直或关键节点强调不足。 |
| `4` | 视觉变化、重复锚点、章节边界和关键强调与叙事推进良好协同，长 Deck 始终容易定位；不存在重大节奏或图文映射问题，仅有少量局部变化或强调可优化。 |
| `5` | 视觉节奏与叙事结构完全共同设计；每类页面、图表、图像和版式变化都承担明确作用，章节定位自然持续，关键节点得到恰当强调，统一与变化达到标杆平衡，无无效重复或突兀跳变。 |

**硬门槛：**

- 视觉序列使读者无法识别主要章节、位置和重点时为 0。
- 多个核心章节仍需重新设计视觉节奏和定位方式时最高为 2。
- 存在实质影响长 Deck 理解的单调区段、弱章节边界或关键节点强调不足时最高为 3。
- 不强制页码、进度条或戏剧化故事弧；等效定位线索有效即可。

## 5. 分数计算

```text
Content Mean   = (C1 + C2 + C3) / 3
Aesthetic Mean = (A1 + A2) / 2
Final Score    = (C1 + C2 + C3 + A1 + A2) / 5
```

`Final Score` 范围为 0–5，保留一位小数。由于五个维度都是整数，最终分天然以 `0.2` 为步长；不转换为百分制，也不做第二次离散化。

C1、C3 或 A1 任一为 `0` 时，另外输出 `critical_failure: true` 和触发维度，但不改变算术平均分。

| 最终平均分 | 报告标签 |
|---:|---|
| 0.0–0.9 | 根本失败 |
| 1.0–1.9 | 严重不足 |
| 2.0–2.9 | 部分实现 |
| 3.0–3.9 | 基本合格 |
| 4.0–4.7 | 良好专业 |
| 4.8–5.0 | 标杆质量 |

## 6. 输出要求

- 五个维度的 0–5 整数分
- Content Mean
- Aesthetic Mean
- 0–5 算术平均最终分
- critical_failure 及触发维度
- 最重要的三个缺陷或标杆依据

### 证据要求

- 每个维度至少提供两条跨不同页面或章节的具体证据；若 Deck 很短，也必须覆盖全部核心部分。
- 0 分必须明确指出未实现的核心能力或导致该维度根本失效的证据。
- 1–4 分必须指出阻止进入下一档的具体页码、章节和缺陷。
- 5 分必须说明已核查的全部章节范围，并给出支持标杆判断的跨页证据，不能只写“整体优秀”。
