# Public font bundle

This directory contains only the OFL/open-source font files used by the public MURAL Presenter
runtime and its deterministic tests. The approved family names, source revisions, and license
declarations are maintained in
[`../skills/mural-presenter/scripts/font_bundle.py`](../skills/mural-presenter/scripts/font_bundle.py).

Do not add fonts from local machines or third-party download sites unless redistribution rights and
source provenance have been reviewed and added to that allow-list.
