# 可执行审美配方：排版、调色板与完成度

本文件在 Style Lock 阶段**完整读取**。它不是合规清单，而是每套 deck 都要落实到 `base.css` 与逐页计划的制作配方。

## 1. 编辑级排版配方

先分配角色，再写页面：

| 角色 | 1600×900 建议区间 | 字重 | 行高 / 字距 |
| --- | --- | --- | --- |
| display / hero | 72–132px | 700–900；编辑衬线可 300–500 | 行高 0.9–1.05；拉丁字距 -0.02～-0.05em |
| 内容页标题 | 48–68px | 650–900 | 行高 1.0–1.15；中文避免过度负字距 |
| 小标题 | 28–38px | 560–700 | 行高 1.15–1.3 |
| 正文 | 24–28px | 400–500 | 行高 1.45–1.65；持续阅读 50–75ch |
| 注释 / 来源 | 18–22px | 400–510 | 行高 1.35–1.5 |

- 全册使用 1.2 或 1.25 的字阶关系，控制在 6–8 个字号档；display 与副题至少形成 `1.5×` 或 `24px` 的落差。
- 普通演讲先建立**标题声部—正文声部—数字声部**三角色。严谨场景可以同族，但不能同字号、同字重、同锚点；学术不等于文档截图。
- 拉丁 display ≥48px 使用 `-0.02～-0.03em` 字距；ALL CAPS 必须 `0.06～0.1em`。中文不使用 uppercase，不以疏字距模拟英文眉签。
- 正文保持自然 rag，不做两端对齐；正文加粗每约 400 字不超过 2 处。pull-quote 靠 32–48px 尺度、偏置与留白成立，不套默认 callout 卡。
- 每页先决定一个 `type_event`：巨标题、hero 数字、编辑引文、章节大字或无；没有 type event 的普通页也要有清楚标题锚点。相邻页不能连续复制同一标题宽度、同一分栏和同一视觉重量。
- 长标题先改断行、宽度与构图，再按字数降档；不得压缩正文安全区或把正文降到地板以下。

Style Lock 中写入：

```text
typography_recipe:
  title_voice: <字体角色与气质>
  title_scale: <display / title / subtitle 数值>
  title_treatment: <字重、断行、锚点、字距>
  body_voice: <正文家族、字号、行高、测量>
  numeric_voice: <KPI / 图表数字角色>
  type_event_map: <哪些页承担尺度事件>
```

## 2. 四层调色板配方

| 层 | 建议像素占比 | 作用 |
| --- | --- | --- |
| 中性层 | 70–90% | `--bg / --ink / --ink-dim / --line / --panel`，控制整册色温与材质 |
| 主/次 accent | 5–15% | 只强调真正的结论、关键路径、主图或分类；先主后次 |
| 语义色 | 0–5% | `--up / --down / --warn / --note`，从系统色派生并有双通道符号 |
| 效果层 | 按需 | 有主题依据的渐变、环境光、颗粒、纸纹、网点或色罩 |

- 先写 `palette_story`，再把 resolved system 的底、墨、线、panel、主/次 accent 映射到 CSS token；禁止只抄一个主色 hex。
- 每一种颜色必须有角色。主 accent 可以形成大色场，但其余元素要退让；多色只在分类、图例或章节编码确有意义时出现。
- 正文对底 ≥4.5:1，大字 ≥3:1。亮色不适合正文时，保留它做填充/线/高亮，文字换深一档。
- 暗底使用带主题色温的近黑与暖白/冷白，不直接纯黑纯白；效果层必须能解释光源、材质或叙事作用。
- 学术、报告、政务的“克制”只降低效果层和装饰量，不删除前景视觉、尺度事件、非对称构图、图表和证据图片。

Style Lock 中写入：

```text
palette_recipe:
  neutral_layer: <bg / ink / dim / line / panel>
  accent_layer: <primary / secondary / allocation>
  semantic_layer: <up / down / warn / note>
  effect_layer: <gradient / light / texture / none + reason>
  contrast_plan: <正文与大字如何过 gate>
```

## 3. 高设计感完成度

- `design_ambition` 默认取 `high`；用户明确要求朴素、法规式或极简时才降为 `restrained`。`high` 表示更强的艺术指导，不等于炫技。
- 多个系统同样合题时，优先选择能产生清楚 `visual_thesis`、标题声部、招牌母题、图表语言与页面节奏的 resolved system，而不是最安全的白底卡片方案。
- 学术场景优先“编辑出版 / 证据展陈 / 科学可视化”的高设计表达：保留准确性与克制，同时主动使用大字阶、非对称栏、图表焦点、Figure 裁图、方法图解和章节节奏。
- 每张页在首稿后回答：第一眼焦点是否足够大；主要视觉是否占据匹配其重要性的面积；删掉边框和卡片后构图是否仍成立；是否只是上一页左右互换。
