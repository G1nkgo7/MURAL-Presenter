# Creative Direction：强模型的主题驱动艺术指导

## 1. 从一句视觉命题开始

先回答：这场演讲让观众进入什么世界？哪一种物理材料、真实界面、地点、时代、对象、数据行为或情绪温度最能代表主题？把答案写成一句可执行的 `visual_thesis`。

好的命题会同时决定颜色、字体、图片行为、线条、页面节奏和特殊页；“现代、简洁、专业、高级”不是命题。

示例结构：

```text
visual_thesis: 把整册做成一份正在展开的实验记录；暗色显微影像是证据场，荧光标记只指出变量与结果。
palette_anchor: 来自附件显微图的黑、灰绿和单一荧光橙。
signature_motif: 样本编号 + 局部放大框，但只承载真实页码、实验组或变量。
```

## 2. 稳定语言与页面变化

全册稳定：字体角色、颜色语义、基础网格、图片处理、线条/圆角、来源格式和母题逻辑。

逐页变化：第一眼焦点、主次比例、阅读方向、媒介占幅、密度、留白位置和章节状态。相邻页面至少改变其中一项；不要只换文案和图片。

建立 2–4 个页族即可，例如：

- editorial evidence：大标题 + 一项主证据 + 边缘注释；
- image narrative：有体量的真实/生成图 + 精简判断；
- mechanism：默认 Canvas 关系主体 + HTML 标签；SVG 只用于简单短标签几何与小型辅助元素；
- data focus：一个结论驱动的图表或数字峰值。

封面、divider、closing 是同一设计 DNA 的三个不同动作，不是普通内容页换背景色。
两种拓扑下都让 `bookends` 同时制作封面与结尾，让 `dividers` 同时制作全部过渡页；
共享视觉记忆，但不要求像素复制。

## 3. 排印先于容器

标题需要“声音”：尺度、字重、宽度、换行、字面密度和与正文的反差。正文需要明确阅读轴，数字需要独立角色。先用排印建立层级，再决定是否需要面板。

- 短标题可成为画面主体；长标题拆出主张与限定。
- 重要数字不放进三张等权 KPI 卡；让最重要数字成为峰值，其余作为证据。
- 卡片只用于真实并列关系。没有边界意义时使用开放式网格、分隔线、色场或留白。
- 中文标签不用拉丁 ALL CAPS/等宽字制造伪技术感。

## 4. 颜色来自内容

先选择 `palette_anchor`，再定义 field/surface/ink/muted/accent。锚点优先级是：用户/品牌
明确色 → 附件或 Hero 图片中的真实色 → 主题对象、地点、材料、文化、物理现象的可见色
→ 才是抽象联想。强调色只服务当前结论、风险、选择、变量或章节身份。

专业不等于米白 + 深蓝；科技不等于蓝紫 glow；学术不等于白纸小标题。真实图片的颜色若承担身份或数据含义，应保留；统一感来自选图、裁切、色温、边界和周边画布。
暖米白、石墨黑、电青或电蓝都只是主题确有依据时的候选，不是安全默认。先从锚点中提出
2–3 个明显不同但合题的候选色场，再选最能支持叙事的一套；不要让解释性文字替代真实
取色。背景优先形成“基础画布 + 主题材质/环境层 + 少量峰值状态”，可用低强度纹理、
生成环境、图片色场或方向性光，不要把一个纯色铺满全册。

用户明确排除某个色系或视觉套路时，该限制同时作用于大面积 field/surface，不能把它
换成“纸张感”“暖中性”或其他名称后继续作为全册主画布。候选方案必须在背景明度、
色温或材质状态上真正不同；最终方案优先选择去掉标题与地名后仍能由主题素材辨认、
而不是可无缝替换到任意咨询或旅行模板的一套。这个判断写进现有配色命题即可，不新增表。

## 5. 主视觉必须承担信息

位图、图表、SVG、Canvas 或强排印中至少一个应成为主阅读事件。微型缩略图、装饰 icon、空面板和背景圆不算主视觉。

- 人物/产品/作品/实验输出：保持可辨认，裁切保护头脸、手势、轮廓、Logo、坐标轴和图例。
- 论文 Figure：只裁视觉主体，保留必要面板、图例和轴，不带大段正文与长图注。
- 机制图：先画关系和方向，再画节点，最后放标签；不要把段落装进流程框。
- 图片与准确文字分层：图负责对象、证据或氛围，HTML 负责可读语言。

## 6. 演讲节奏

整册需要张弛，而不是每页同密度：

```text
建立语境 → 提出张力 → 给证据 → 解释机制 → 展示结果 → 形成选择/行动 → 收束
```

视觉峰值应对应叙事峰值。呼吸页可以稀疏，但必须有统治性标题、图像、数字或母题；大片没有方向的空白不是呼吸。

### 呼吸节奏

密集证据页之间穿插有意识的低密度页面（可选，非机械间隔）：

- **纯排印**：一句结论 72–132px 占满画布，仅配说明或来源；声明 `editorial-typography`。
- **巨数字**：一个决定性指标超大号呈现，正文只一句解读。
- **满图金句**：全出血位图或生成氛围 + `special-safe` 内短句。
- **空间停顿**：divider 变体或极窄内容配强母题/色场。

呼吸页是节奏工具，不是固定模板——只有证据密集区连续四五页且听众需要喘息时才安排。
它也不是缺少想法的降级：每个呼吸页仍必须有统治性视觉事件和明确的阅读锚点。

## 7. 联系表拒绝标准

在 overview 尺度以模型判断拒绝；这些是审美提示，不是固定计数器或聚合分数：

- 连续三页相同左右分栏或等权卡片；
- 封面像普通标题页，结尾像三栏总结；
- 图片缩成角落附件，图表缩成装饰；
- 普通页内容只占局部窄带，外围空间没有职责；
- 学术页复刻论文正文/整页截图；
- 每页重复同一个 glow、假编号或无意义技术注；
- 全册只有“无错误”，却没有可复述的视觉命题。

Review 优先修最影响整册气质的共同根因：标题声音、主视觉体量、页面轮廓重复、色场漂移、附件证据缺席。不要为清除无可见影响的 lint 损伤已经成立的画面。
