# 开工前设计校准

Orchestrator 在首次制作页面或提交 Image/Slide 前完成一次本节校准，并把结果写进现有 `deck.md` 的“视觉故事板”和“整体设计规范”。这是一个简短的创作决定，不新增 JSON schema、页型字段、状态文件或审批步骤；后续作者直接沿用，除非用户要求、事实或关键素材改变。

## 紧凑合同

用一张短表写清以下决定，每项只保留会改变画面的内容：

| 决定 | 必须回答的问题 |
| --- | --- |
| 受众与观看条件 | 谁在什么距离、时长和场景中看；第一遍必须读懂什么？ |
| 创意命题 | 哪个属于本题材的对象、媒介或关系统领整册，而不是套用通用风格词？ |
| 主导视觉 | 听众主要观察、比较或操作什么证据；哪个对象最值得优先投入；哪些页承担视觉峰值？ |
| 色彩角色 | 颜色从题材的什么线索推导；背景、内容面、文字、主强调和辅助强调各做什么？写实际色值。 |
| 字体角色 | 题材与观看条件需要怎样的展示和阅读语气；实际覆盖页面语言的家族、字重与层级是什么？不要求各角色换家族。 |
| 网格与锚点 | 安全区、主要对齐线、页眉/页码等稳定锚点是什么；主视觉通常可占多大？ |
| 结构家族 | 本册只需要哪 2–4 种表达结构，分别服务聚焦、并置、比较、过程或证据阅读中的什么任务？ |
| 图像方向 | 使用照片、原 Figure、生成插画、代码图形或文档证据的边界；裁切、质感和禁用替身是什么？ |
| 节奏与反默认 | 哪里需要放大、换挡、留白或收束；本册明确拒绝哪些默认模板习惯？ |

合同必须能让不同页面作者作出一致决定，不能只写“高级、简洁、科技感、杂志感”。用户给参考图或参考站时，只提取字体对比、密度、对齐、色彩角色、裁切逻辑和材质感，不复制其文字、标志、资产或受保护构图。

用一句具体的画面取舍把命题落地：纪实对象靠主体尺度与环境关系，比较命题靠共同基线与差异强调，语言或文化命题靠展示字形、断句与材质关系。它们是推导示例，不是题材分支；实际选择至少进入排印、空间、媒介或裁切中的一项，不能只写色值。把必需证据与延伸解释分开，投影页不把完整研究变成屏显清单，自学页仍保留独立理解的必要条件。

先把素材、构图和展示排印的主要时间投入最能留下记忆的对象；其余元素服务它，不把精力平均分给所有页面小部件。默认保持页面边缘安静：除必要页码、来源、图例和局部标注外，不为“看起来完整”添加装饰性小字、状态标签、胶囊、常驻信息栏或无叙事作用的页眉。

## 从意图选结构

先判断页面要完成的沟通任务，再选择结构。优先使用 `base.css` 中可组合的 `deck-layout` 原语作为稳定起点，具体比例和视觉语言仍由内容决定：

| 沟通任务 | 合适起点 | 不作为默认答案 |
| --- | --- | --- |
| 建立主题与观看动机 | `hero`：一个主视觉加简短标题/问题 | 顶部标题栏加多块内容卡 |
| 解释一个证据或结论 | `focus`：标题锚点加大尺度证据区 | 大标题旁堆若干同权摘要 |
| 图文、问题/答案或对象/解释 | `split`：主次明确的并置 | 两边无关系的独立面板 |
| 共同尺度下比较 | `compare`：共享基线的等权区域 | 各自口径不同的卡片墙 |
| 时间、步骤或因果推进 | `sequence`：有方向的连续区域 | 小箭头装饰在无关卡片上 |

这些名称是可选 CSS 原语，不是页型枚举。作者可以组合、调整或不用它们，但不能让每页重新发明安全区、最小尺寸和基本间距。

## 联系表拒绝项

整册联系表出现以下情况时，说明设计合同没有兑现，应合并为一次有范围的修复：

- 缩略图尺度没有明确焦点，主证据被缩成装饰；
- 封面像普通内容页或信息仪表盘；
- 连续页面重复同一网格、卡片数和密度，却没有叙事理由；
- 计划中的视觉峰值没有尺度变化，或视觉峰值落在无关页面；
- 相同语义的颜色、字体、页眉、页码或图像处理在不同 Owner 页面漂移；
- 通用科技渐变、平均卡片墙、装饰性标签或小图标盖过题材本身；
- 页面边缘被装饰性小字、状态条、胶囊或常驻信息栏占满；
- 必须先读小字才能知道页面看什么；
- 开场、转场或结尾没有表现出与其叙事职责相符的节奏。

新奇本身不是目标。证据清楚、投影可读、跨页一致和本题材独有的视觉指纹优先。
