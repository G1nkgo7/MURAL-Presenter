# 74 种风格路由索引

本索引只帮助 Orchestrator 定位风格方法。用户明确指定的风格优先；表中的适用线索和风险提醒用于默认选择与实现判断，不是按受众或主题排除风格的规则。目录未收录的要求也可直接落实，不必改成表内风格。

用户已指定风格时，先用名称或相关关键词定位索引行，不从头扫描全部风格。没有既定方向时，可结合内容、素材和演示条件比较少量候选，选定后只读取链接对应的一个详细小节。链接锚点与 `## ID · 名称` 一一对应；用章节 ID 定位后读完该节，到下一个二级标题前停止，无需通读五份文件。ID 仅用于定位，不新增必填规划字段。

全册方向已由 Orchestrator 确定时，Slide 延续该方向；需要方法细节时，按 Orchestrator 提供的文件与章节 ID 读取对应卡，不重新选择全册风格。将选中的方法转译为当前内容的构图、排印、图像行为与跨页节奏，不复制完整案例。素材或工具限制影响实现时，在现有交接中说明取舍，并尽量保留用户要求的关键特征。

复杂场景、角色、材质与光影优先使用位图素材；SVG 与 HTML 图形适合精确数据、简单关系和必要标注，不用大段 SVG 重画复杂插画场景。卡中的节奏指尺度、密度与阅读路径，不替换内容大纲；数量建议随内容调整，不作为机械审美门槛。
