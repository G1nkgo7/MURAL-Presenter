# 自然、文化、教育与生活：风格方法

本文件供[风格索引](../style-index.md)按原 ID 路由。只读取已选章节；Slide 已有全册方向时，按 Orchestrator 指定的卡节补充方法，不重新选风格。颜色、形状、图像处理与排印可从材料、地域、对象或教学动作中取得依据。

用户明确的风格优先，风险提醒用于调整表达，不按年龄、受众或主题排除选择。复杂角色、文化场景、材料与笔触优先采用位图；SVG 或 HTML 图形用于精确数据、简单关系和必要标注。事实图像与概念示意分清。
以下节奏描述视觉上的远近、密度与笔触变化，不是一套固定教学或文化故事；用户的页序、内容与使用方式决定解释深度。

## 04 · 水墨中国 Chinese Ink Wash

- 构图：墨势方向、远近层次与现代网格形成张力；留白承担视线和停顿。
- 排印：短标题可用书写声线，正文/数字保持现代清楚，印章只作单点信号。
- 图像：真实纸墨、山水或文化对象优先，不把所有照片滤成水墨。
- 节奏：浓墨开场 → 淡墨解释 → 细节证据 → 再次聚焦 → 一笔收束。
- 风险提醒：假宣纸铺底、全页书法、无职责空白和古风边框。

<a id="style-12"></a>

## 12 · 手绘插画 Hand-drawn

- 构图：一个手绘对象或机制路径承担主视觉，批注沿动作/关系组织。
- 排印：手写只给少量注释和招牌字，正文使用稳定阅读字体。
- 图像：复杂对象与场景优先使用统一笔触、线宽和颜色的位图插画；简单关系可用线图，真实身份与数据保持可核验。
- 节奏：整体对象与局部关系使用相同笔触，重点处增加批注或尺度差，复杂度服从当前解释。
- 风险提醒：涂鸦填空、字体幼稚、每页彩色贴纸和无法核验的手绘事实。

<a id="style-13"></a>

## 13 · 生活方式 Lifestyle/Instagram

- 构图：连续照片裁切、对象细节和轻编辑标注建立观看关系；宫格只在确有分类或对照作用时使用。
- 排印：精简标题、自然 caption 和少量手写/serif 点缀，商业信息保持清楚。
- 图像：真实人物、产品、空间与动作优先，滤镜/色温全册一致且不过度。
- 节奏：场景远景与对象细节形成尺度对比，保持色温与 caption 层级，文字页保留同源编辑语法。
- 风险提醒：圆角照片卡墙、空泛小红书语气、无真图和标签覆盖主体。

<a id="style-16"></a>

## 16 · 卡通可爱 Cartoon/Cute

- 构图：一个角色/对象引导阅读，形状圆润但空间所有权清楚，一页一个认知动作。
- 排印：大字号、短句、友好反馈；正文仍用清晰字体，角色台词不替代结论。
- 图像：统一角色比例和表情；事实对象需要真实时，角色只做引导而不伪装证据。
- 节奏：角色或对象的位置帮助衔接观察，重点页放大动作，解释页减少无关表情和装饰。
- 风险提醒：成人或危机议题需校准角色语气；彩色 sticker、多角色和小字容易抢走主要判断。

## 18 · 国潮 Chinese Neo-traditional

- 构图：从真实传统母题抽取轮廓、节奏或色带，以现代比例和强标题重组。
- 排印：现代展示字与传统短语分工；正文不使用书法体，英文/数字风格统一。
- 图像：器物、纹样、建筑或人物需有来源；传统色来自对象而非固定红金。
- 节奏：传统母题在关联页延续轮廓与色带，整体与细部改变尺度，事实区保留清楚现代排印。
- 风险提醒：龙凤祥云堆砌、红金默认值、所有边缘加回纹和文化 cosplay。

<a id="style-20"></a>

## 20 · 日式无印 Japanese/Muji

- 构图：功能网格、低重心对象和安静负形共同建立秩序，细节留在近景。
- 排印：克制无衬线/明朝体分工，字阶细腻但投影可读；标签极少。
- 图像：自然材料、产品和空间使用柔和真实光线，裁切保留触感。
- 节奏：安静全貌与触感近景交替，负形与字阶稳定，重点靠尺度而非新增装饰表达。
- 风险提醒：泛米白、过小灰字、假禅意空白和内容密集却不重排。

<a id="style-26"></a>

## 26 · 北欧简约 Scandinavian

- 构图：功能优先的清晰网格、自然材质和一个温暖对象形成对重。
- 排印：人文无衬线、适度行宽和清楚层级；强调色从材料/环境提取。
- 图像：木、织物、空间、人物活动使用自然光，避免过度滤镜。
- 节奏：对象、材质与功能细部采用相关比例，温暖强调色集中在当前重点，网格持续稳定。
- 风险提醒：家居 stock 图、低饱和即高级、柔和圆角卡和无事实的生活感。

<a id="style-38"></a>

## 38 · 黑板粉笔 Chalkboard

- 构图：围绕一条推导/教学路径组织公式、图解和重点，板书空间有先后。
- 排印：粉笔字只用于标题/批注，核心公式和正文保持清楚、对齐、可读。
- 图像：适合课堂示意和工作坊记录；真实对象可像教具般嵌入而非变插画。
- 节奏：沿实际解释逐步突出板书区域，已建立的公式和参照保留位置，重点用局部圈注或字重表现。
- 风险提醒：粉笔语气需贴合当前读者；彩色涂鸦、伪手写小字和黑板纹理容易压低对比。

<a id="style-39"></a>

## 39 · 便签手账 Sticky Notes/Journal

- 构图：时间、观察、证据或行动条目围绕一条主线，便签数量和层级受控。
- 排印：正文以阅读字体为主，手写只给批注/日期；每张条目有明确关系。
- 图像：研究照片、票据、草图或真实记录承担证据，胶带只作少量装订动作。
- 节奏：相互关联的条目保留分组与位置，重点通过纸面尺度或批注突出，不为手账风格增加工作坊流程。
- 风险提醒：等权便签墙、随机旋转、贴纸装饰、用手账感掩盖没有结论。

<a id="style-41"></a>

## 41 · 自然生态 Nature/Eco

- 构图：真实物种/地貌/环境、尺度和观察路径构成探索；因果关系可叠加简洁图解。
- 排印：自然材料色配科学标签系统，物种名、单位和图例严格。
- 图像：真图承担 identity/evidence；颜色从对象取样，不机械使用绿色。
- 节奏：环境与对象细部保持空间关联，科学解释沿用稳定图例和自然材料色，关键观察放大。
- 风险提醒：叶片 icon、绿色口号和缺少具体对象的“自然感”容易流于装饰；卡通示意与真实生态证据需区分。

<a id="style-42"></a>

## 42 · 海洋水彩 Ocean/Watercolor

- 构图：水体方向、深浅层次和真实海洋对象结合，流动留白引导下潜/迁移。
- 排印：标题可柔和，科学正文和数据保持高对比；文字避开复杂晕染。
- 图像：真实海洋照片/物种优先，水彩作为情绪/过渡层，不替代证据。
- 节奏：深浅色层与水体方向延续观看路径，主体轮廓和科学标注始终清楚，晕染强度随重点变化。
- 风险提醒：大面积蓝绿晕染容易使主体不辨，文字需要清楚底面；字体语气按用户要求与读者调整。

<a id="style-47"></a>

## 47 · 织物布纹 Fabric/Textile

- 构图：纤维近景、编织方向、纹样重复与成品轮廓建立材料—结构关系。
- 排印：标题像织标/展签，正文安静现代；线条粗细呼应纤维而非模拟花边。
- 图像：真实布料、工艺和手部动作大面积展示，颜色从纱线取样。
- 节奏：纤维微距与成品轮廓形成尺度差，编织方向和色系延续，解释页使用同源线条。
- 风险提醒：廉价纹理铺底、材质图缩成邮票、假缝线和所有内容装布框。

<a id="style-49"></a>

## 49 · 节日庆典 Festival

- 构图：一个仪式焦点、时间/空间路径和节奏性装饰组织庆典，而非到处撒元素。
- 排印：主标题高能，日期/地点/行动清楚；装饰字只服务节庆名称。
- 图像：真实仪式、人群、食物或地点优先；彩旗/烟花作为方向和节奏。
- 节奏：焦点页提高色彩与对象尺度，信息页减少装饰，真实日期、地点或行动保持稳定层级。
- 风险提醒：彩虹配色、装饰遮字、通用烟花 stock 图和每页都像活动海报。

<a id="style-53"></a>

## 53 · 清新文艺 Fresh Literary

- 构图：单张意象图、短文本和编辑散文节奏形成感受；负形需有视线和停顿职责。
- 排印：人文衬线/无衬分工，标题轻但尺度足；引文依靠字阶与位置建立层级，边框有明确分组作用时再使用。
- 图像：真实旅行、阅读、人物或自然细节，统一柔和色温而不过曝。
- 节奏：单张意象图与细部阅读保持共同色温，留白形成观看停顿，解释所需内容不因文艺语气被删去。
- 风险提醒：空泛小清新、过小灰字、泛米白与植物装饰、信息密集硬套。

<a id="style-55"></a>

## 55 · 婚庆浪漫 Wedding/Romance

- 构图：人物/花材/场地作为主舞台，柔光层次与仪式路径组织信息。
- 排印：优雅展示字用于名字/誓言，正文和日期保持清楚；装饰不过界。
- 图像：真实情感对象优先，肤色和花材色统一；caption 避开人物脸部。
- 节奏：人物全景与细节裁切保留情感方向，花材和柔光在重点处集中，文字信息使用安静底面。
- 风险提醒：无真实对象、粉色默认值、花框压字、手写体铺满正文。

<a id="style-59"></a>

## 59 · 儿童幼教 Children/Preschool

- 构图：大对象、大动作和一步一认知；反馈区独立，阅读顺序可由颜色/角色引导。
- 排印：大字号、短句、清楚字形；标签和图例不要依赖未识字儿童阅读。
- 图像：真实教具/物体或统一儿童插画；危险/科学事实保持准确。
- 节奏：对象位置和反馈符号连续，难点处放大并减少干扰，信息增量依据实际教学任务调整。
- 风险提醒：复杂数据、小字、过多角色、把“可爱”变成装饰噪声。

<a id="style-62"></a>

## 62 · 韩系现代 Korean Style

- 构图：冷静留白、精细照片裁切和一处非对称字体事件构成时尚节奏。
- 排印：标题字阶细腻、正文干净，tracked Latin 只作眉签；中文可读优先。
- 图像：美妆、时尚、产品和生活空间采用均匀柔光与克制背景。
- 节奏：照片全貌与精细裁切切换尺度，字阶与柔光保持连续，重点由对象而非标签数量决定。
- 风险提醒：浅灰圆角卡、过小细字、只靠字体“高级”和无图任务硬套。

<a id="style-63"></a>

## 63 · 中式古典 Classical Chinese

- 构图：轴线、窗格、章法或卷轴方向经现代网格转译，主对象拥有清楚尺度。
- 排印：宋/黑分工，书写字体只给短题签；数字、表格和正文保持现代。
- 图像：真实建筑、器物、书画或文献优先，纹样只作结构提示；历史图像的纸边只有在原作幅面
  本身有意义时才完整保留，否则裁到主体或用同色 matte 融入主画布。
- 节奏：轴线或卷轴方向贯穿关联页，原物全貌与局部细读改变尺度，题签与正文声部稳定。
- 风险提醒：仿古边框、全页书法、回纹祥云堆叠、红金默认配色，以及用小题签/印章取代封面主标题。

<a id="style-66"></a>

## 66 · 美食餐饮 Food/Culinary

- 构图：食物/原料主图与温度、质地、产地或步骤形成感官—知识关系。
- 排印：菜名/主张有食欲感，配方、数字和步骤清楚；菜单确需并列条目时保留分类与主次，不让所有小卡等权。
- 图像：真实食物、制作动作和产地优先，暖光需保留真实色泽。
- 节奏：食物全貌、质地近景与必要步骤采用统一光色，重点变化放大，信息页不被餐具装饰挤占。
- 风险提醒：无真图、油腻滤镜、每页菜品宫格和装饰餐具 icon。

<a id="style-71"></a>

## 71 · 非遗手作 Heritage Craft

- 构图：原物、匠人之手、工艺步骤、局部细节和时间痕迹建立证据链。
- 排印：当代编辑网格承接传统材料，展示字体只作短招牌；工序编号稳定。
- 图像：器物、纹理和过程占主视觉，颜色从真实材料与颜料取样。
- 节奏：手、材料与工序细节互相定位，纹理尺度和编号语法连续，关键工艺占据清楚主区。
- 风险提醒：卡通或仿古处理若替代原物证据，会丢失材料细节；还需留意对象过小和工艺顺序不清。

## 72 · 敦煌古风 Dunhuang

- 构图：壁画原作/洞窟空间、藻井秩序和局部矿物色注释形成“观看—解读”关系。
- 排印：当代正文配短题签；洞窟号、年代、颜料和图像身份边界清楚。
- 图像：真实壁画/洞窟图优先，允许同图不同安全裁切；生成图只能做标明的示意。
- 节奏：原作全貌与局部色层互相定位，洞窟或壁画参照保留，矿物色与题签在关联页延续。
- 风险提醒：卡通或生成示意需与壁画原作区分；满页飞天纹样、数据口径压缩错误和固定红绿金套皮会妨碍解读。
