# 编辑、纪实与影像：风格方法

本文件供[风格索引](../style-index.md)按原 ID 路由。Orchestrator 选定后只读取对应小节，将方法转译为当前内容；Slide 需要细节时也可按 Orchestrator 给定的卡节读取，延续已有全册方向。

这些是编辑与影像方法，不是整页模板；风险提醒服务于用户要求的实现，不按受众或题材排除风格。复杂场景优先用位图，精确图表、简单关系与标注保持清楚。
节奏用于安排景别、密度和阅读停顿，不决定需要哪些内容章节；沿用户大纲与实际证据展开。

<a id="style-03"></a>

## 03 · 杂志编辑 Magazine Editorial

- 构图：一页一个编辑焦点；主图、标题、standfirst 与边注形成非对称主辅关系。
- 排印：展示标题与正文以明显尺度差建立层级；必要的真实栏目与身份信息低调呈现，不自造刊号或制作标签模拟“杂志感”。
- 图像：身份图大裁切，细节与全貌跨页呼应；caption 有独立空间，不压在复杂主体上。
- 节奏：用主图尺度、阅读密度、留白与稳定网格区分强调和解释；不因减少层级就缩小关键证据。
- 色场：背景与阅读面的变化服务当前内容，同时保留整册色彩和排印的亲缘关系；证据原件的纸面或色彩仍可保留。
- 风险提醒：重复同一分栏或仅靠衬线字体模仿杂志，容易弱化编辑焦点；竖排、细线和装饰标记需保留自然阅读路径，不虚构内容元信息。

<a id="style-15"></a>

## 15 · 新闻报道 News/Journalism

- 构图：结论式头条统领一个现场对象或主图表，直接标注证据，不做后台 dashboard。
- 排印：标题短而可验证；正文采用紧凑单/双栏，数字、时间与事实限定清楚；出处定位留在分页证据。
- 图像：纪实照片承担人物/地点/事件身份；图表承担比较，二者不互相降成缩略卡。
- 节奏：头条、主图与证据细部形成尺度差，必要比较沿用同一网格；不强行把每页改写成新闻更新。
- 风险提醒：完整复刻报纸、小字号密集多栏、虚构头条、黑白红三色无差别铺满。

<a id="style-36"></a>

## 36 · 复古报纸 Vintage Newspaper

- 构图：报头、主标题、原始材料与侧栏形成印刷层级，但用现代演示尺度重排。
- 排印：衬线头条、窄体元信息与少量 rule；正文保持演示可读，不追求报纸信息密度。
- 图像：原始剪报、档案照片和票据保留边缘与年代痕迹，关键证据局部放大。
- 节奏：头版式重点与档案细读切换密度，纸张质感不遮住证据，不要求额外增加时代对照或当代结论。
- 风险提醒：泛黄滤镜覆盖一切、撕纸贴纸、四五栏小字和无法追溯的伪档案。

<a id="style-37"></a>

## 37 · 胶片摄影 Film/Photography

- 构图：宽幅镜头、人物近景、空间全景和细节静帧交替；字幕关系低调稳定。
- 排印：标题进入图像安全区，解释页回到安静编辑网格；必要的真实时间地点低调呈现，不模拟场记板的制作编码。
- 图像：真实照片保持主体、视线和环境关系；统一色温/颗粒但不抹去证据真实性。
- 节奏：建立镜头 → 靠近对象 → 切换视角 → 证据停顿 → 拉远收束。
- 风险提醒：每页电影海报、过度暗角、无法辨认的氛围裁切和无图片时硬做胶片框。

<a id="style-45"></a>

## 45 · 漫画分镜 Comic/Storyboard

- 构图：分镜大小服从解释步骤、观察重点或实际叙事；视角、景别和阅读方向连续可追踪，不必制造冲突。
- 排印：对白只保留决定性句子，旁白与数据证据分声部，不让气泡塞满画面。
- 图像：真实案例可用照片序列，概念故事可用统一插画；每格主体和动作必须清楚。
- 节奏：关键观察可跨栏放大，相关动作或状态保留参照；按实际内容衔接，不要求补出事件与决策故事。
- 风险提醒：所有格子同尺寸、速度线装饰化、字体过多、用虚构角色替代真实证据。

<a id="style-74"></a>

## 74 · 当代艺术策展 Contemporary Curation

- 构图：单件对象拥有主舞台；全貌、局部与展签通过尺度差和非对称留白建立观看关系。
- 排印：画廊式呼吸配高精度标签系统；标题像策展命题，不像活动海报。
- 图像：作品、材料或空间以足够大的尺度呈现；裁切服务比较和细节观察，不做等框陈列。
- 节奏：全貌、细部与对照对象用尺度差连接，空白承担停顿和视线导向，不代替必要解释。
- 风险提醒：泛米白“高级感”、过小作品图、无职责留白、所有对象套同一种圆角框。
