# 活力、艺术与实验：风格方法

本文件供[风格索引](../style-index.md)按原 ID 路由。只读取已选章节；Slide 已有全册方向时，按 Orchestrator 指定的卡节补充方法，不重新选风格。以清楚的主动作组织变奏；借鉴其他局部手法时，让它服务已有方向。

用户指定的表现力优先，风险提醒不把正式、学术或成人受众列为禁用场景。复杂角色、空间与材质优先采用位图，SVG 或 HTML 图形用于精确数据、简单关系和必要标注；读者仍应看清当前结论与事实边界。
以下节奏是视觉变化，不是内容大纲；沿已有论证调整景别、密度与强调，不因采用某种风格强加故事、冲突或关卡。

<a id="style-07"></a>

## 07 · 孟菲斯 Memphis

- 构图：非对称几何、尺度跳跃与节奏点围绕一个主对象/主张，形状承担分组或方向。
- 排印：粗短标题与安静正文形成对比；标签数量受控，字形不跟随每个图形变化。
- 图像：人物/产品可用干净 cutout；几何只提供舞台，不遮住真实对象。
- 节奏：形状密度在开场/峰值升高，解释页减少元素并保持同一语法。
- 风险提醒：正式评审也可采用活泼表达，关键是留出清楚证据区；随机波点和彩色碎片容易变成信息噪声。

<a id="style-08"></a>

## 08 · 包豪斯 Bauhaus

- 构图：非对称轴线、几何尺度和少量基础色映射真实层级、方向或分组。
- 排印：标题与数字成为构图，正文保持稳定；字体关系清楚而非历史 cosplay。
- 图像：真实对象可与圆/线/矩形对位，几何不做无意义填空。
- 节奏：轴线跨页延续，主几何在峰值改变比例或方向，结尾回到基本形。
- 风险提醒：彩色圆随机散布、每页红黄蓝同拼法和图形与内容无关。

<a id="style-09"></a>

## 09 · 波普艺术 Pop Art

- 构图：对象放大、强主张、半调与色块冲突形成传播力度。
- 排印：短标题像声音事件，正文/数据保持一层清楚底板；拟声字只用于真实动作。
- 图像：消费对象、人物或媒介图像可高对比处理，但身份仍应辨认。
- 节奏：放大对象与安静证据区形成张弛，半调和强色在重点处集中，不额外编造文化冲突。
- 风险提醒：正式内容需独立的阅读与证据层；彩虹噪声、满页漫画元素和低质图片放大容易削弱判断。

<a id="style-11"></a>

## 11 · 像素复古游戏 Pixel/Retro Game

- 构图：像素网格、关卡地图、状态条和选择路径表达真正的阶段/规则。
- 排印：像素字体只给短标题/标签，中文正文使用清晰字体；数值像 HUD 但真实。
- 图像：游戏/数字史可用原始截图或统一像素插画，避免伪造特定作品。
- 节奏：沿真实阶段或变量改变高亮与地图位置；不是游戏叙事时不增加关卡、Boss 或闯关文案。
- 风险提醒：证据报告需保留真实图片和图表的精度；所有图像低分辨率化或无机制的 8-bit 装饰容易模糊信息。

<a id="style-21"></a>

## 21 · 蒸汽波 Vaporwave

- 构图：复古数字空间、雕塑/界面对象与透视网格表达怀旧未来的时间错位。
- 排印：一条展示标题配干净正文；日文/故障字不得成为无意义装饰。
- 图像：生成/档案素材需统一粉紫—青色时空配方，保留必要的示意或年代限定；来源定位留在素材登记。
- 节奏：对象近景与复古空间层交替，色温和透视延续同一语法，重要证据回到清楚阅读面。
- 风险提醒：科技或事实汇报需清楚的结论层；默认粉紫渐变、低对比和无语境雕塑容易掩盖主题。

<a id="style-25"></a>

## 25 · 装饰艺术 Art Deco

- 构图：对称门廊、阶梯比例与细金几何围绕单一对象，建立仪式和垂直感。
- 排印：高挑展示标题、宽字距眉签和克制正文分工；中文标题保持可读。
- 图像：建筑、珠宝、历史照片或产品材质优先，金线只是边界和节奏。
- 节奏：门廊比例与细部裁切形成尺度变化，细金线只在关键层级增强，不为仪式感另编故事。
- 风险提醒：数据密集时，满页金框与仪式构图容易压缩证据区；黑金俗套和无关花纹也会分散焦点。

<a id="style-28"></a>

## 28 · 涂鸦街头 Graffiti/Street

- 构图：一个喷绘主声部、粗标记路径和真实城市/人物对象形成冲突与方向。
- 排印：手写/喷漆只给短主张，正文保持清晰；标签像现场标记而非贴纸。
- 图像：街头文化、运动和艺术需真实地点/人物或授权视觉；颜色从现场取样。
- 节奏：喷绘主张与安静的事实区形成强弱对比，保留贯穿的标记方向；不默认增加冲突或宣言。
- 风险提醒：正式内容可保留喷绘主张并设置稳定阅读区；随机纹理、字体过多和涂鸦覆盖容易遮住证据。

<a id="style-29"></a>

## 29 · 剪纸折纸 Paper Cut/Origami

- 构图：纸层切面、折线和展开关系表达层级、包含、转化或工艺。
- 排印：文字停在独立纸面，层级由纸边和阴影建立；正文不跨折痕。
- 图像：文化、教育和机制示意可用纸艺位图呈现复杂层次；简单展开关系可用图形，真实对象仍可嵌入顶层窗口。
- 节奏：完整形态 → 展开 → 内层 → 重组 → 新形态。
- 风险提醒：精密数据需保持平面清楚；假阴影压字、所有内容变纸片和无关系折角容易扰乱层级。

<a id="style-30"></a>

## 30 · 几何构成 Geometric Composition

- 构图：大色块、圆/方/三角与比例关系映射真实分组、冲突或层级。
- 排印：标题与几何共享轴线，正文保持一个安静阅读面；数字可成为尺寸事件。
- 图像：对象可被几何裁切但主体完整；色块数量服从分类数，不随意增加。
- 节奏：基本形建立 → 关系变化 → 复杂组合 → 峰值重构 → 简化收束。
- 风险提醒：图形无语义、每页拼贴不同、正文被切碎和过多颜色。

<a id="style-31"></a>

## 31 · 线条艺术 Line Art

- 构图：连续线、轮廓和局部 callout 揭示结构、过程或优雅对象。
- 排印：细线与正文有明确粗细对比，标题不必同样纤细；标签靠近目标但不交叉。
- 图像：产品轮廓、机制和人物姿态可线性表达，身份真图可与线稿局部叠加。
- 节奏：轮廓 → 局部 → 关系 → 完整系统，线条密度随解释深度变化。
- 风险提醒：复杂数据比较需保留精度与标签；细线投影容易丢失对比，通用 outline icon 也可能抹掉对象特征。

<a id="style-32"></a>

## 32 · 双色调 Duotone

- 构图：两种直接色、负形、半调和少量套印偏移建立统一记忆与前后关系。
- 排印：纸色/黑承担阅读，第二色承担信号；文字不使用低对比双色叠印。
- 图像：人物/产品照片可转双色但主体可辨；分类数据超出双色表达能力时，用标签、线型或符号补充。
- 节奏：双色比例跨页变化，峰值让第二色扩张，结尾重新收为单信号。
- 风险提醒：多分类图表不能只靠双色区分；每页换色和照片细节消失也会削弱统一性与识别。

<a id="style-46"></a>

## 46 · 蒙德里安 Mondrian

- 构图：粗线网格和红黄蓝黑白的面积比例编码真实分类、优先级或空间关系。
- 排印：文字位于稳定色块，黑线承担结构；大标题可跨一个主单元但不跨多色噪声。
- 图像：艺术/分类教育可叠加对象 cutout；色块必须与内容映射一致。
- 节奏：基本网格 → 单元变化 → 对照 → 复杂峰值 → 回到清晰秩序。
- 风险提醒：分类无意义、色块数量不受控、把任何报告套成红黄蓝方格。

<a id="style-57"></a>

## 57 · 古典欧式 Classical European

- 构图：古典比例、中轴/拱券与现代留白共同组织原作、建筑或历史对象。
- 排印：经典衬线展示与现代正文分工，装饰首字/铭牌只作局部。
- 图像：真实绘画、雕塑、建筑和档案细节优先，边框让位于作品。
- 节奏：原作全貌与局部细读采用相关比例，边框与留白随主体尺度变化，不要求补写时代叙事。
- 风险提醒：巴洛克花边铺满、仿古羊皮纸、正文装饰体和历史元素混搭。

<a id="style-65"></a>

## 65 · 运动活力 Sports/Dynamic

- 构图：动作裁切、斜向轴、计时/比分和轨迹线围绕真实运动瞬间。
- 排印：短主张、高对比数字与克制说明；斜体/压缩字只给速度事件。
- 图像：真实运动员/装备/场地优先，动作方向决定裁切和对重。
- 节奏：运动方向和斜轴在关联页连续，重点瞬间扩大，数据页稳定下来；不虚构对抗或胜负。
- 风险提醒：治理与静态数据需稳定阅读层；全元素倾斜、装饰速度线和海报小字容易干扰关系判断。

<a id="style-69"></a>

## 69 · 二次元动漫 Anime/Otaku

- 构图：角色视线、赛璐璐色面和分镜景别引导当前知识或对象；角色不是必需内容，分镜感不靠制作标签。
- 排印：展示字服务作品气质，正文与数据保持清晰；气泡不承担长解释。
- 图像：按任务与素材使用要求选取角色原作，或采用明确的原创位图；角色跨页保持一致，事实与概念示意分清。
- 节奏：用景别、视线和色面连续性承接既有论证；讲算法或知识时围绕真实关系展开，不默认编世界观、冲突或角色回归。
- 风险提醒：角色图需核实身份、登记来源，不能代替现实证据；随机动漫脸和角色遮挡也会削弱信息。

<a id="style-70"></a>

## 70 · 萌系潮玩 Kawaii/Blind Box

- 构图：单一主角色/手办拥有雕塑感舞台，收藏陈列与比例对照解释系列关系。
- 排印：大而友好的标题配清晰产品信息；角色名/编号像藏品铭牌。
- 图像：真实潮玩产品或统一原创角色的位图渲染；材质、比例和光线全册一致。
- 节奏：主体全貌、材质近景与系列对照保持光线和比例一致，不因潮玩风格附加收藏邀请。
- 风险提醒：角色设计不清或多个小角色同框时，主结论容易失焦；字体语气需与用户意图一致。
