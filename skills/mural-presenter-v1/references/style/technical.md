# 商业、产品、技术与空间：风格方法

本文件供[风格索引](../style-index.md)按原 ID 路由。只读取已选章节；Slide 已有全册方向时，按 Orchestrator 指定的卡节补充方法，不重新选风格。产品、机制、界面、数据事件或空间关系可作为视觉主体；素材不足时保留用户要求的关键特征，说明实现取舍。

风险提醒用于调整表达，不按受众或场景否定用户选择。复杂空间、材质与光影优先采用位图；精确数据、简单关系和必要标注适合 SVG 或 HTML 图形，不将复杂场景重画成大段 SVG。
节奏指对象尺度、层次、明暗和阅读路径的变化；不预设产品路线图、异常故事或技术章节，内容由任务与证据决定。

<a id="style-01"></a>

## 01 · 科技未来 Tech/Futuristic

- 构图：真实技术对象/机制占主舞台，精确信号线和层级色场解释连接与状态。
- 排印：几何标题配高可读正文；技术标签短而少，mono 只给真代码、接口和坐标。
- 图像/图表：真实产品与实验图承担身份或证据，生成概念图只作明确示意；图表突出主要数据关系。
- 节奏：全貌与机制细部通过尺度切换，精确信号色在重点处集中，关联页保留相同参照。
- 风险提醒：通用蓝紫渐变、发光球、空设备框和四张功能卡。

<a id="style-06"></a>

## 06 · 拟物写实 Skeuomorphic

- 构图：一个可识别物件或控制表面作为空间中心，层级来自真实厚度、材质和操作关系。
- 排印：文字像铭牌/刻度般附着于对象边界，正文仍留在独立阅读区。
- 图像/图表：优先真实产品或高质量渲染；阴影、反光和纹理必须符合同一光源。
- 节奏：整体轮廓与材质或操作近景相互定位，界面层级与光源跨页连续。
- 风险提醒：假皮革木纹、多个小拟物 icon、阴影遮字和无对象时硬做表面。

<a id="style-10"></a>

## 10 · 赛博朋克 Cyberpunk

- 构图：暗场城市/网络对象与一条霓虹路径建立冲突、追踪或控制关系。
- 排印：主标题可高能，正文使用清晰无衬线；故障字只出现于短信号。
- 图像/图表：真实/生成城市、人物或设备需统一夜景光线；数据编码用少量稳定信号色，分类较多时补充形状或标签。
- 节奏：霓虹路径贯穿关联对象，重点处提高亮度或改变景别，解释区保留稳定的清晰底面。
- 风险提醒：企业或连续阅读内容需清楚的证据层；满页粉青 glow、低对比小字和无语义霓虹容易盖住信息。

<a id="style-17"></a>

## 17 · 渐变流体 Gradient Fluid

- 构图：定向流场表示连续变化、迁移或能量，不把渐变当无主题背景。
- 排印：标题与流向互相咬合，正文落在稳定静区；颜色不穿过核心文字。
- 图像/图表：渐变色来自案例对象或连续变量；叠加真实对象时保留清晰轮廓。
- 节奏：流场方向跨页延续并在峰值改变尺度，结尾收束为稳定色域。
- 风险提醒：信任渐变、随机 radial glow、分类数据需要离散编码却强行连续色。

<a id="style-22"></a>

## 22 · 玻璃拟态 Glassmorphism

- 构图：透明层只表达前后关系、信息深度或可交互状态，底层必须有可辨对象。
- 排印：面板内层级简短，高对比文字不跨越复杂底图；少量边缘高光定义空间。
- 图像/图表：界面、地图或空间数据可在玻璃层间组织；主图不可被磨砂完全遮住。
- 节奏：从整体空间进入一层细节，再回到系统；每页玻璃层数量受控。
- 风险提醒：透明层在打印或复杂底图上容易丢失边界；留意低对比、满页毛玻璃卡和所有内容同框。

<a id="style-23"></a>

## 23 · 新拟态 Neumorphism

- 构图：同色浮雕只用于少量可操作控件或产品触感，页面主体仍靠网格和尺度。
- 排印：文字不压在凹凸边缘，状态必须有颜色以外的形状/标签通道。
- 图像/图表：适合软硬件界面和触觉产品特写；数据图表保持平面清楚。
- 节奏：展示触感的页作为局部峰值，其他页回到克制产品编辑语言。
- 风险提醒：密集内容或暗场中，浮雕边界和状态容易不清；补充可辨的标签与对比，避免每个容器都使用双向阴影。

<a id="style-24"></a>

## 24 · 暗黑极客 Dark Geek/Terminal

- 构图：输入、运行轨迹、输出和异常形成可复算链路，不把终端当背景贴图。
- 排印：mono 只用于真代码/API/ID/日志，解释正文使用阅读字体；行长受控。
- 图像/图表：代码片段、调用图和运行结果互相定位，异常信号只高亮一处。
- 节奏：代码局部与实际结果互相定位，当前解释段高亮，其余信息弱化但仍可读。
- 风险提醒：伪代码装饰、每页终端截图、绿字黑底全文和把日志密度当深度。

<a id="style-27"></a>

## 27 · 工业风 Industrial

- 构图：真实设备/现场、接口、流程节点和责任边界共同建立系统图景。
- 排印：粗标题只承担章节，正文与技术标注清晰；单位、警告和状态稳定编码。
- 图像/图表：设备大图/剖面与流程图互相定位，颜色表示状态而非装饰。
- 节奏：设备全貌、局部剖面与关系图按现有论证切换尺度，标注和状态编码稳定。
- 风险提醒：混凝土纹理铺满、铆钉装饰、设备小 icon 墙和无方向流程框。

<a id="style-33"></a>

## 33 · 故障艺术 Glitch Art

- 构图：受控错位、通道偏移或断裂提供媒介质感或强调变化，保留清晰阅读层；视觉效果本身不证明发生了真实故障。
- 排印：核心文字保持一份清晰母版，故障副本不得破坏可读；正文无效果。
- 图像/图表：局部处理真实界面/对象，前后对照显示“正常—故障”。
- 节奏：清晰区域与局部错位形成张力，关键证据保持稳定；强度变化服务现有重点。
- 风险提醒：用 glitch 泛化未来感、每页抖动、重要数据无法辨认和多色噪声。

<a id="style-34"></a>

## 34 · 等距插画 Isometric

- 构图：统一轴测空间承载部件、层级和物流关系；视角全册固定。
- 排印：标签沿局部坐标系排列，主结论留在空间外的稳定区域。
- 图像/图表：城市、系统、仓储和架构可使用统一轴测位图，连接与对象尺度保持一致；需要精确比较的数据和简单关系单独绘制。
- 节奏：总览和局部放大保留一致轴测视角，视线沿真实连接移动，需要比较时沿用同一坐标。
- 风险提醒：人物情绪和真实证据需清楚表达，不能仅由轴测图代替；小部件过多容易缩成邮票。

<a id="style-40"></a>

## 40 · 太空星空 Space/Galaxy

- 构图：真实天体、轨道、尺度或任务路径成为主体，深空只提供空间参照。
- 排印：标题像任务命题；距离、时间、单位和注释高对比且远离星云噪声。
- 图像/图表：优先 NASA/机构真图、轨道示意和尺度比较；生成图必须标示意。
- 节奏：远景与近景建立尺度差，距离和轨道参照在关联页延续，解释区避开星空噪声。
- 风险提醒：与主题无关的宇宙背景、随机星点、蓝紫 glow 和假科学 HUD。

<a id="style-43"></a>

## 43 · 金属质感 Metallic

- 构图：单件硬件、表面剖面或材料样片成为主舞台；反光方向揭示形体。
- 排印：冷静、窄幅、精确；标签像工程铭牌但不挤入高光区域。
- 图像/图表：真实产品/渲染和微观材料图优先，图表采用冷灰结构与单色信号。
- 节奏：完整形体与表面近景交替，反光方向和材料色连续，数据页用同源冷灰结构。
- 风险提醒：缺少材料依据时，大面积拉丝纹和多个金属 icon 容易显得失真；银灰文字也容易丢失对比。

<a id="style-44"></a>

## 44 · 霓虹灯牌 Neon Sign

- 构图：一条灯管路径或招牌文字成为夜景焦点，暗部保留足够结构层级。
- 排印：霓虹只用于短标题/信号，正文使用非发光高对比字体。
- 图像/图表：适合夜生活、城市商业和娱乐；灯色来自真实场景或品牌。
- 节奏：亮招牌开场，内容页减少 glow，峰值再次点亮，结尾留下单一信号。
- 风险提醒：长正文与技术解释需要非发光阅读层；辉光糊边和每个边框都发光会削弱重点。

<a id="style-48"></a>

## 48 · 地图蓝图 Blueprint/Map

- 构图：坐标、剖面、尺度、编号和 callout 揭示空间/结构关系；总览与局部互相定位。
- 排印：工程注释与主结论分声部，mono 只用于坐标、尺寸和技术标签。
- 图像/图表：地图、设备、网络或建筑可用少量线型和结构色；真实对象可叠加半透明剖面。
- 节奏：总图与局部节点互相定位，缩放保持方向、坐标和图例，变化处用单一强调色指出。
- 风险提醒：随机电路线、无意义网格、所有页同一蓝底白线和过密小标注。

<a id="style-56"></a>

## 56 · 3D 立体 3D Render

- 构图：单一 3D 对象、空间装置或机制模型占据主舞台，视角和光源跨页一致。
- 排印：文字停在稳定平面，不烘焙进生成图；尺寸/接口标注沿对象轮廓。
- 图像/图表：优先可信产品渲染或位图概念图；概念生成图标“示意”，背景和材质配方统一，必要的精确标注单独叠加。
- 节奏：同一对象的全貌、剖开或近景保持视角和光源关系，静态页也能独立读懂，不强制增加旋转动画。
- 风险提醒：多个廉价 3D icon、漂浮胶囊、文字乱码进图和每页随机视角。

<a id="style-60"></a>

## 60 · 未来主义 Clean Sci-fi

- 构图：清洁空间层、精确光线和单一高对比信号表达未来对象与关系。
- 排印：几何展示标题配高可读正文；线条和 glow 只服务深度、选中态或方向。
- 图像/图表：真实 UI/原型或统一生成概念图承担主体，精确机制关系单独保持清楚。
- 节奏：清洁空间中的远近层次与局部高亮信号交替，关键关系集中展现，解释页降低光效密度。
- 风险提醒：霓虹球、蓝紫渐变、满页玻璃卡、与主题无关的宇宙景。

<a id="style-68"></a>

## 68 · 科幻 HUD Sci-fi/HUD

- 构图：信息环、准星、范围与状态层围绕一个真实对象，不创建无中心仪表盘。
- 排印：读数、单位和状态有稳定角度/基线，主结论保持水平可读。
- 图像/图表：适合航空、安防、设备监测；用于事实展示的 HUD 读数对应真实变量或动作，概念界面标明示意。
- 节奏：对象与局部读数切换焦点，状态高亮有真实对应，信息环不改变阅读基线。
- 风险提醒：假参数、圆环遮住主体、长正文、把电影界面当普通科技装饰。

<a id="style-73"></a>

## 73 · 沉浸式光影 Immersive Light

- 构图：光场方向、人物/空间尺度和投影边界共同表达体验；视点随叙事移动。
- 排印：文字停在空间静区或独立场签，不跨越高亮投影；字幕短而克制。
- 图像/图表：用空间照片或可信位图渲染建立尺度，序列镜头说明进入、包围与离开；精确路径与标注可独立叠加。
- 节奏：全景与细部沿空间方向衔接，用光场范围和主体尺度建立张弛，始终保留文字静区。
- 风险提醒：空间依据不足时，单靠渐变和 glow 容易失去尺度；保持对象焦点与清楚的阅读层。
