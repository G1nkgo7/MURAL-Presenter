# 字体与排印

排印先服务受众、场景与主题语气，再选择家族。正式研究、课堂推理、品牌发布和文化展览
不应都落到一套“高级衬线＋中性正文”；丰富也不等于每个元素换一种字体。

## 先分角色，再选字体

| 角色 token | 工作 |
| --- | --- |
| `--font-display` | 封面、转场、强主张与少量决定性文字 |
| `--font-title` | 内容页标题链 |
| `--font-body` | 正文、表格、坐标与需要持续阅读的解释 |
| `--font-number` | 指标、读数与数字主张 |
| `--font-annotation` | 短批注、引语、人文注释 |
| `--font-mono` | 代码、坐标、测量值等需要等宽秩序的位置 |

这些是声部，不要求六个不同家族。展示体、毛笔、手写、草书或活泼字体只承担短而清楚的表达，
不能因为它好看就用来排整页正文和数据标签。长册主要通过尺度、层级和构图变化，不靠不断新增字体。

## 选择与实际激活

可按题材定向查看 [字体路线数据](../typography-routes.json) 的一个路线对象，作为家族、角色搭配和 fallback 的选择参考；
关键词查询只返回命中片段，需要全部角色时用返回行号继续展开该对象，不必读完整数据库。
选中的实际家族、字重和用途写入 deck.md 的整体设计规范，角色 token 直接写入 base.css。
目录不是自动执行配置，文稿中的路线名不会替你设置字体；不要另写一套 Markdown 字段等待后台页面准备应用。

常用方向包括：

| 路线 | 更适合的语境 | 不应机械套用 |
| --- | --- | --- |
| executive-clean | 企业沟通、简洁清楚的工作汇报 | 所有题材的默认审美答案 |
| tech-product | 产品、系统与技术演示 | 仅靠字体制造技术内容 |
| tech-forward | 工程、产品、机制与数据 | 依赖发光文字制造科技感 |
| academic-institutional | 学术、研究、政策与机构 | 只因有数据就牺牲主题语气 |
| editorial-documentary | 人物、调查、历史与纪实 | 所有“有故事”的内容 |
| culture-refined | 艺术、文化、展览与器物 | 通用金色与毛笔字堆砌 |
| brand-luxury | 品牌、消费、酒店与生活方式 | 密集数据标签与长正文 |
| sport-poster | 体育、活动与强节奏海报 | 长篇机构论证 |
| experimental-graphic | 艺术实验与创意表达 | 模糊事实和降低可读性 |
| education-friendly | 教学、培训与工作坊 | 把所有文字变成手写 |
| children-playful | 明确的儿童、漫画或轻松手作 | 仅因听众年轻就幼态化 |

精确家族与 fallback 从当前目录选择，以作者 CSS 和实际渲染确认应用，不把这张方向表当字体清单。
用户字体与明确的字体意图仍有优先级。自定义上传沿现有授权配置；也可在共享 CSS 引入合法可用的公网字体，
核对实际家族、字重和许可，不把网络加载失败当作字体已生效。字体准备只验证实际资源，不替作者选择视觉方向。
例如一册明确需要活泼中文短标题的演示，可选择覆盖汉字的展示家族，并由 Orchestrator 在 base.css 中落实角色栈和字重，而不是把代码放入 deck.md：

```css
:root {
  --font-display: "Smiley Sans", "Noto Sans SC", sans-serif;
  --font-title: "Noto Sans SC", sans-serif;
  --font-body: "Noto Sans SC", sans-serif;
  --font-number: "Space Grotesk", "Noto Sans SC", sans-serif;
  --font-display-weight: 400;
}
```

这是该语境的搭配示例，不是默认路线。研究、数据或正式沟通可以让展示与正文同家族，通过字重、字号、行宽和留白形成层级；需要有性格的中文展示字时，先确认实际汉字覆盖，再选与内容语气相符的家族，不靠拉丁 fallback 或描边特效制造假差异。

家族栈与字重各有职责：数值变量保持数值，缺字回退保留真实栈顺序，不因名字类似某种风格自动换家族。

Slide 读取 base.css 的角色 token，不逐页改家族。作者声明的公网字体保持实际定义；离线交付需要可合法打包的字体。加载失败和声部不合适分开处理：前者修资源，后者由 Orchestrator 调整全册意图。

## 搭配不是家族排行榜

### 研究与机构

标题有稳定的权威感，正文和图表优先清楚。衬线和无衬线都可成立；判断它是否服务证据组织。
元信息保持次级，手写批注只有在讲述中确有用途才出现，不能稀释严谨语气。

### 技术与数据

标题、测量值与正文形成清楚分工。技术感来自对齐、尺度、数值秩序和准确注释，不是发光、全大写或满屏等宽字。
中文标题与拉丁数字可以来自不同家族，但字重、基线与视觉大小要协调。

### 编辑、杂志与人物叙事

展示声部可以更有轮廓，阅读声部保持稳定。图像、引文与标题形成具体的编辑关系；
不要因为选择了衬线就默认居中、小主体和大片无职责空白。

### 文化、人文与教学

手写或楷体可表达批注、器物或讲述语气，不自动接管整个课堂。文化标题的颜色来自主题对象、材料或色彩体系，
不默认金色。展示性的笔画必须有足够尺寸与完整轮廓，正文仍可从后排阅读。

### 活泼品牌与儿童内容

表现性字体用于真正需要的短标题或语气节点，长段落与精确信息回到阅读声部。
不要用描边、阴影、光晕来补救本身难读的字体；缩小它的职责比叠加效果更有效。

## 文字、色彩与空间

- 纸底上的编辑文字可以用有色深墨，不必全部深藏青；服从本册实际色彩契约。
- 深底上的标题先保证明暗对比，饱和色用于关键词、状态或决策，不把每个词都强调。
- 图像叠字根据真实裁切的静区选择明/暗侧，需要时使用局部 scrim，不套统一近白标签配方。
- 字号由角色与内容决定；标题凝练不了时按语义拆层级并给足宽度，不只不断缩小。
- 数字、单位、短人名和术语尽量成组，标签贴近对象，避免孤行和跨区跳读。

## 中文与双语

中文展示字字距接近零，拉丁负字距不能机械搬到粗中文；行高需要让笔画舒展。
双语标题有主次，第二语言不等量重复占据同一层级。表格、轴与图例维持阅读字体。
拉丁展示家族缺中文时，合法 CJK fallback 是字体栈的一部分，不是选型失败；
反过来，首位家族名正确也不能证明页面实际出现了想要的声部，需要看真实渲染。
当页面主要是中文、而拉丁展示家族不含汉字时，中文标题实际会落到后面的 CJK 字体；如果这个字体与正文相同，只有拉丁字母和数字获得了展示声部。视觉契约明确需要有性格的中文大标题时，应选择真正覆盖中文的展示家族，或明确把拉丁展示体只用于数字/英文，并用构图、尺度和字重承担中文标题的差异；不能把 `Sora + 正文字体 fallback` 之类的栈写法本身当作中文展示字体已经生效。

## 渲染后看什么

先看听众能否马上分清标题、主张与证据，再看展示/阅读/批注是否各有职责。
确认中文不局促、数字与单位不破碎、拉丁与中文视觉尺度协调、数据标签从投影距离仍可读。
如果每页悄悄变成中性正文声部，检查实际字体解析与字形覆盖；不要凭计划里的家族名声称已兑现。
如果去掉一种字体能让系统更清楚，就减少家族；如果展示声部与题材无关，就调整全册决定，而非局部补特效。
封面、转场或 hero 页应真实出现本册选定的展示声部；如果最终每页都退回中性无衬线，说明字体契约没有兑现。
重复职责使用稳定声部、尺寸阶梯和标签字距；不要让相邻页面因为不同 Owner 的局部选择变成不同字体系统。
图片叠字按实际裁切选择明暗、局部 scrim 和行长；不要把统一近白标签配方套到所有照片，也不要用描边、阴影或发光补救本身不清楚的字体。
