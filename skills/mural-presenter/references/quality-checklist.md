# 演示文稿质量清单

Slide Group 用“单页检查”完成组内自检；Review 使用整份清单完成全册验收。先看像素，再用 DOM 和机检定位。

## 1. 单页检查

### 1.1 内容与表达

- 标题、正文、图表和结论围绕同一个页面职责。
- 听众能在短时间内说出本页结论。
- 普通内容页除主题句外，还有证据、机制、对比、案例、行动或边界中的至少一种有效支撑。
- 屏显文案面向听众，不出现页面角色、素材路线、证据编号、文件路径和制作状态。
- 文案具体、自然、可直接表达；不以生僻比喻、行业黑话、过度口语或“不是 X，而是 Y”“关键结论”“N 条路径”等公式化句式代替信息。
- 标题、副标题、图片角标、badge、callout、图例和页脚没有无增量重复。
- 来源留在讲稿或独立参考文献页，不挤进普通页面。

### 1.2 视觉语义

- 图形中的对象、关系、方向和结论与标题一致。
- 形状与连接符合整册 `shape_grammar`：同一形状不在相邻页面随意换语义，装饰形状不冒充证据。
- 需要方向的流程线有箭头或等价编码。
- 图例、颜色和形状含义清楚，没有互相矛盾。
- 方法页具有领域特征，不是通用圆形、矩形和连线的装饰组合。
- 图表的类别、series、图例、标签和数值完整对应。
- 计划要求的图片、Figure、图表或解释图真实上屏，并且具有足够面积。
- Logo、图标、装饰纹理和微型缩略图不冒充实质性配图；真实图片、截图或证据图的机会已经按计划兑现。

### 1.3 构图与空间

- 第一眼焦点清楚，阅读路径自然。
- 主视觉大小与重要性相称，不缩在角落或中央小团。
- 主要内容合理使用安全区，没有“外围大空白、中央拥挤”。
- 卡片内部没有大块无职责死白；短内容不过度使用高大等高卡。
- 留白用于聚焦、节奏、方向或换场，而不是因为内容没有被设计。
- 同级元素对齐、等高关系合理，间距有节奏。

### 1.4 文字与技术完成度

- 正文、数据、节点标签和结论不低于 `--fs-min`。
- 没有意外断行、孤立短尾或孤立标点。
- 没有文字裁切、溢出、遮挡、页脚冲突和破图。
- 对比度足够；图片上的文字有稳定可读区。
- 图片保持比例，主体和 `protected_parts` 未被裁掉。
- `subject-only` 使用真实 Alpha 抠图，不露出偶然矩形底色。
- Canvas、SVG、CSS 和 JS 共用一致坐标系统。

### 1.5 设计完成度

- 页面兑现整册视觉方案，而不是回退到通用模板。
- 图片、色场、材质和排印服务主题，不是随机装饰。
- 有信息意义的原始颜色没有无理由被灰阶化。
- 页面只有一个主要设计动作，其余层级为它服务。
- 辅助文字有观众价值且不重复。
- 不用 emoji、星芒字符和伪技术注冒充设计。

## 2. 特殊页检查

### 封面

- 有一个统治性焦点，标题与主图形成明确关系。
- 长标题选择适合字数的构图，不靠盲目放大挤压。
- 短标题通过主图、尺度和空间关系建立张力，不因居中而空洞。
- 不显示页码、进度、运行标记和无意义元信息。

### 章节页

- 章节号、标题和一句承诺形成主信息团。
- 有图片、色场、排印或母题形成视觉对重。
- 多张章节页在字体、编号、标题锚点和图片处理上有亲缘性。
- 每章通过重心、方向、裁切或章节状态产生变化。
- 画布没有大片无职责留白。

### 结尾页

- 回应封面或核心命题，不承担详细总结和参考文献。
- 核心信息团简洁；没有明确非对称配重时水平、垂直光学居中。
- 不显示页码、页脚、进度、`END` 和“感谢聆听”等套话。

### 特殊页修改不退化

- 修改前后比较主焦点、主体尺度、视觉重心和阅读路径。
- 局部告警消失但主图被切断、色带变重、元素被误删或留白恶化，仍判定为退化。
- bbox 只作为线索；单页 Vision 没有看到真实问题时，不为清除告警破坏原构图。

## 3. 整册检查

### 3.1 叙事与节奏

- 页序形成清楚推进，每页有独立职责。
- 页面家族服务 `primary_scenario` 的听众任务：决策页能支持判断，教学页能支持学习动作，学术页能回到原始证据，叙事页能形成情绪推进。
- 各章没有机械复制同一页面脚本。
- anchor、dense 和 breathing 页面形成节奏起伏。
- 参考文献与结尾分别承担证据和收束职责。

### 3.2 视觉一致性

- 字体角色、颜色语义、图片处理和图形语法一致。
- 画布家族连续；章节换色有进入和退出承接。
- 母题有主次与缺席，不在多数页面重复粘贴。
- 相邻页不是同一几何只换文案，也没有突然换成另一套 Deck。

### 3.3 内容与配图

- 每页内容充分且屏显语义唯一。
- 具名人物、作品、产品、场地和案例的图片机会已经兑现，或有明确不可得原因。
- 图片的视觉分量与其计划职责一致。主图、视觉证据和情绪锚点在投影尺度下清楚可辨，不是角落缩略图或空卡片里的点缀。
- 不以 `<img>` 存在、路径有效或“已经放了一张图”代替构图判断。
- 附件中的 must-show 图片真实出现。
- 生成图不冒充具名真实对象的证据；概念图承担的角色清楚。
- 图表和论文 Figure 与原始证据一致。

### 3.4 投影风险

- 联系表尺度能看清标题层级和主要结论。
- 小字、低对比和细线不会在投影时消失。
- 所有页面都在安全区内，没有页脚漂移和背景接缝。
- 特殊页已用单页 PNG 复核。

## 4. 机检结果怎么用

以下信号需要进一步定位，不自动等于必须修改：

- `OVERLAP`、`CROWDED`、`DECOR-OVERLAP`；
- `SPARSE`、`IMG-LONELY`；
- `ABS-LAYOUT`、`CUSTOM-BODY`；
- bbox 相交和行内文字联合框。

以下问题通常属于硬伤：

- `OVERFLOW`、`TEXT-OVERFLOW-BOX`、`FOOTER-PUSHED`；
- `BROKEN-IMAGE`；
- 已由像素确认的遮挡、裁切、页脚覆盖和不可读；
- 变更后的源码晚于最终 PNG；
- 最终页面未被 Vision 覆盖。

机器告警与像素冲突时，保留视觉更好的版本，并记录 `checker mismatch`。不要以“告警清零”替代质量判断。

## 5. 完成标准

- Slide Group：本组每页由组联系表覆盖，特殊页和复杂页已看单页，变化页有新鲜像素。
- Review：全册联系表已分批看完，特殊页已看单页，问题账本覆盖全部页面。
- 修改发生后：变化页完成前后对比，没有新增退化。
- 最终交付：事实正确、讲稿对齐、`present.html` 构建成功。
