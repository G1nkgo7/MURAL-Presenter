# 学术研究与严肃评审

## 听众任务

让听众判断研究问题是否重要，方法是否成立，证据是否支持结论，限制和贡献是否清楚。

## 叙事骨架

研究问题与缺口 → 方法与对象 → 核心结果 → 解释与机制 → 局限 → 贡献与下一步。

## 证据对象

- 论文原始 Figure、表格、实验图像和方法示意；
- 样本、变量、对照、评价指标和统计边界；
- 结果中的类别 × 系列 × 数值映射；
- 真实实验输出，如光谱、显微图、CT、界面和日志；
- 引用、出处、限制和不确定性。

## 常用页面家族

| 页面职责 | 适合的表达 |
| --- | --- |
| 问题与缺口 | 一张关键证据图 + 清楚问题陈述 |
| 方法 | 对象—操作—测量—输出的领域链 |
| 结果 | 原始 Figure 裁图或准确重绘的图表 |
| 解释 | 结果、机制与边界的可追溯关系 |
| 贡献与限制 | 与基线比较，避免宣传式夸大 |

## 视觉与节奏

画布可以安静，但 Figure、图表和方法证据应占据应有面积。用字阶、对齐、注释和局部强调建立秩序，不用大量小卡。Figure 必须裁到独立图，不把整页论文缩小后放入图片框。

## 容易退化的方向

- 用概念图冒充实验结果；
- 图表重绘时错列类别、series 或数值；
- 为统一风格把具有语义的伪彩、热图或标注改成灰阶；
- 只核对计划摘要，不回到原表头和最终像素。

## 规划交接

逐页计划标明 Figure 编号、原始页、裁图资产、图注、来源和这张图支持的具体结论。方法页写清领域对象、方向和真实输出，不能只写“圆形—矩形—数据”。
