# 决策与经营分析

## 听众任务

让决策者迅速看清现状、差距、驱动因素、选项、风险和下一步。演示不是数据仓库，而是一条可追溯的判断链。

## 叙事骨架

结论与问题界定 → 现状证据 → 原因或分群 → 方案比较 → 风险与边界 → 决策和行动。

需要先铺背景时也应尽快出现判断锚点；不要把全部结论拖到最后一页。

## 证据对象

- 趋势、结构、分布和前后差异；
- 对象 × 指标 × 值的准确比较；
- 因果链、约束条件和敏感因素；
- 方案的统一评估维度、成本、收益与风险；
- 责任、时间和可验证结果。

## 常用页面家族

| 页面职责 | 适合的表达 |
| --- | --- |
| 决策锚点 | 一个结论 + 一个关键证据对象 |
| 现状诊断 | 趋势图、结构图、分群或基准对比 |
| 驱动因素 | 可追溯因果链或贡献拆解 |
| 方案选择 | 同维度比较、权衡轴或情景矩阵 |
| 落地路径 | 路线图、责任与时间，不做装饰流程 |

## 视觉与节奏

使用宽内容轨道、稳定标题轴和清楚的数据层级。让证据页与结论页交替：证据页可以紧凑，判断页应聚焦。真实业务场景、产品或空间只有在能帮助识别对象、理解约束时才使用，不用无关商务图库。

## 容易退化的方向

- 每页都是同一种 KPI 卡或仪表盘；
- 只展示数字，不说明比较口径和决策含义；
- 方案两栏使用不同维度，视觉上可比但语义不可比；
- 用“闭环、抓手、赋能”等抽象词替代具体对象和行动。

## 规划交接

逐页计划写清：本页判断、证据对象、比较口径、决策含义和视觉主次。图表必须保留类别、series、数值、单位、时间与来源。
