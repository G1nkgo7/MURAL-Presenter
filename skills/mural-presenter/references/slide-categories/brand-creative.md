# 品牌、文化与创意叙事

## 听众任务

让听众进入一个世界，感受主题，记住核心主张，并理解关键人物、作品、场景或品牌动作。

## 叙事骨架

强开场 → 世界与人物 → 冲突/张力 → 过程与变化 → 高潮 → 回响或邀请。

商业品牌可把“过程与变化”替换为体验、产品和行动，但仍保持情绪推进，而不是变成卡片目录。

## 证据对象

- 人物、作品、地点、材质、产品和场景；
- 真实影像、档案、片段、局部细节和声音线索；
- 叙事转折、视觉对照和前后变化；
- 品牌姿态、体验触点和可记忆符号；
- 必要的事实、出处和边界。

## 常用页面家族

| 页面职责 | 适合的表达 |
| --- | --- |
| 世界建立 | Hero 图、空间画面或强排印 |
| 人物/作品 | 可辨认影像 + 编辑式信息层 |
| 叙事推进 | 分镜、对照、局部放大或连续图像 |
| 高潮 | 单一强焦点、尺度事件或沉浸画面 |
| 回响 | 回到开场母题，但改变语义或视角 |

## 视觉与节奏

字体、图片调色、颜色语义和形状语法建立亲缘性；重心、裁切、方向和媒介制造变化。允许更大胆的编辑式构图、纹理、渐变和图片背景，但一页仍应有一个主要动作。

## 容易退化的方向

- 用小卡片墙讲人物、作品和场景；
- 每页重复同一个场记、坐标、星芒或编号；
- 编造技术注、档案号和年份制造“高级感”；
- 只追求氛围，导致事实、对象和叙事关系看不懂。

## 规划交接

逐页计划写清主角、镜头尺度、情绪动作、图片处理、文字与画面的关系，以及本页如何承接前后。真实人物、作品和地点优先搜索真实图；概念氛围可生成，但不能替代身份识别和事实证据。
