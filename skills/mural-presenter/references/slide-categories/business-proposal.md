# 商业计划、招商与提案

## 听众任务

让合作方相信机会真实存在，理解产品或项目为何值得参与，并看清合作方式、回报逻辑、风险与下一步。

## 叙事骨架

机会与愿景 → 用户和场景 → 产品或体验 → 差异与证据 → 运营/商业机制 → 合作权益与回报 → 行动。

## 证据对象

- 真实空间、产品、服务现场和目标人群；
- 市场规模、需求变化和竞争参照；
- 用户旅程、运营流程和体验触点；
- 收益结构、成本结构、权益和合作边界；
- 里程碑、团队能力与可验证案例。

## 常用页面家族

| 页面职责 | 适合的表达 |
| --- | --- |
| 机会开场 | Hero 场景 + 一句明确机会判断 |
| 产品体验 | 真实图、空间图、界面或体验序列 |
| 差异证明 | 同维度对比、案例前后或证据拼贴 |
| 商业机制 | 价值流、角色关系、收益结构 |
| 合作收口 | 权益、条件、里程碑和明确下一步 |

## 视觉与节奏

真实产品与场景应获得足够面积。Hero、图字分屏、体验序列和商务数据页交替，形成“相信—理解—计算—行动”的节奏。高端不等于空白和金色，温馨也不等于整册奶油卡片。

## 容易退化的方向

- 纯色商务模板覆盖所有页面；
- 只有愿景口号，没有运营和回报机制；
- 主图被缩成小缩略图，大片画布由泛泛文字占据；
- 把“受众、招商资料、内部版本”等生产信息写上屏。

## 规划交接

逐页计划写清图片承担识别、体验、证据还是情绪职责，并给出实际素材路线。涉及回报的数据必须标注口径；通用示例要明确是规划示意，不伪装成真实经营结果。
