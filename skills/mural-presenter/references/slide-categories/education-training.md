# 教学与培训

## 听众任务

让学习者从当前能力出发，建立直觉、理解概念、看到示范、完成练习，并能把方法迁移到新问题。

## 学习链

定向与情境 → 激活已知 → 分步理解 → 示例/反例 → 练习与反馈 → 迁移问题。

每页只承担一个清楚的学习动作，但同一动作可以由图、问题、演示和短说明共同支撑，不等于每页只有一句话。

## 证据对象

- 真实现象、地图、遥感图、实验、作品或操作界面；
- 分层示意、前后变化和逐步标注；
- 示例、反例、常见错误和判断依据；
- 可观察结果与反馈；
- 迁移任务和开放问题。

## 常用页面家族

| 学习动作 | 适合的表达 |
| --- | --- |
| 引发注意 | 真实场景、问题或反常现象 |
| 建立模型 | 分层图、过程图或对照图 |
| 演示推理 | 逐步高亮的图层、证据和结论 |
| 检查理解 | 选择、排序、找错或短任务 |
| 迁移应用 | 新场景 + 清楚提问，不提前塞满答案 |

## 视觉与节奏

投影字阶优先，阅读路径单一。关键图像和解释视觉承担教学，不用装饰图分散注意。通过聚焦页、解释页、练习页和呼吸页交替保持节奏；“简洁”不能退化成巨大空白。

## 容易退化的方向

- 一次展示全部推理与答案；
- 把讲义段落直接缩小搬上屏；
- 用抽象几何代替领域对象；
- 练习页只有问题，没有观察材料或判断条件。

## 规划交接

逐页计划写明学习者进入本页时已知什么、离开时能做什么、观察对象和讲述节拍。需要动画时，只规划顶层内容依次出现，不依赖复杂交互才能理解最终静态画面。
