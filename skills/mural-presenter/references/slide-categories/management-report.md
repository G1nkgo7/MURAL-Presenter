# 管理汇报与组织沟通

## 听众任务

让组织成员对齐事实、进度、责任和优先级，知道已经发生什么、为什么、接下来谁在何时完成什么。

## 叙事骨架

目标与口径 → 进展与结果 → 偏差与原因 → 关键事项 → 决策/协同请求 → 下一阶段行动。

## 证据对象

- 目标与实际、同期与环比、计划与完成；
- 项目状态、风险、依赖和责任人；
- 事件、客户、现场和团队成果；
- 决策请求及其影响范围；
- 下一阶段的时间、里程碑和验收标准。

## 常用页面家族

| 页面职责 | 适合的表达 |
| --- | --- |
| 状态总览 | 少量关键判断，不做密集监控墙 |
| 进展复盘 | 目标—实际—原因—动作的连续结构 |
| 风险升级 | 风险、影响、触发条件和责任路径 |
| 项目串联 | 时间线、依赖关系或责任地图 |
| 管理决策 | 决策项、选项、推荐和后续动作 |

## 视觉与节奏

标题应可串成一段管理叙事。数据页、现场页和行动页交替，避免连续十页状态卡。版面强调稳定阅读轴，但允许关键页通过尺度、图片或色场形成峰值。

## 容易退化的方向

- 一页塞满所有指标和项目；
- 颜色只表示装饰，不表示状态或优先级；
- 页脚、角标和标题重复“月报、复盘、进展”等无增量词；
- 将内部机密标签、文件名或会议元数据展示给听众。

## 规划交接

逐页计划明确状态语义、时间口径、责任对象和需要听众采取的动作。报告中的来源、内部注释和待确认项进入讲稿或事实边界，不挤进普通页面。
