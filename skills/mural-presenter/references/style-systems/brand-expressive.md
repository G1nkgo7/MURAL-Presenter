# 品牌与表达系统

## 声波霓虹

- **签名**：深色舞台上用橙色节拍和声波方向建立娱乐能量。
- **颜色**：橙为主节拍，电柠、青或品红选择一个辅助角色。
- **字体**：粗黑/活泼展示字、无衬线正文、等宽节目标签。
- **图片与形状**：人物、舞台和活动现场为主；声波、条带和圆点用于节奏，不冒充数据。
- **招牌动作**：实心条、分镜、带圆点的列表行和局部霓虹描边。
- **适合**：音乐、娱乐、直播、潮流活动。

## 玻璃糖果

- **签名**：高饱和色场与透明表面塑造年轻、轻快的产品世界。
- **颜色**：青柠、玫粉、暖橙中选择有限角色；背景可深可亮。
- **字体**：圆润、几何或 playful 展示字配清洁正文。
- **图片与形状**：产品和人物仍是主角；药丸、玻璃和大圆角服务层级。
- **招牌动作**：光泽药丸、局部玻璃、大圆角和高光渐变。
- **适合**：消费产品、年轻品牌、创意提案、社媒活动。

## 金色指数

- **签名**：冷静纸面与少量金色流光共同表达精确价值感。
- **颜色**：浅灰纸、近黑文字、冷蓝数据和克制细金线。
- **字体**：优雅衬线标题、无衬线正文、专门数字声部。
- **图片与图表**：金融、资产或材质主图必须真实可得；图表极简、留白清楚。
- **招牌动作**：金色沙丘/流光主图、细金线和大尺度数字。
- **fallback**：无招牌素材时退到冷蓝灰 + 细金线 + 强排印，不生成廉价金属纹理。

## 黑金实验

- **签名**：黑金或奶油渐变画布中，以单张主视觉和精致排印形成高端实验感。
- **颜色**：金色或暖赭只点关键焦点，避免整页金色描边。
- **字体**：展示衬线、清楚正文、手写体只做极短点缀。
- **图片与形状**：主图、拍立得或材质卡承担内容；星芒和荧光笔只在表达需要时出现。
- **招牌动作**：单张主视觉、精细线、局部高亮和大胆留白。
- **fallback**：没有照片时用渐变色场 + 强排印 + 一个准确图形，不堆空相框。

表达型系统允许大胆，但屏显信息仍需唯一、自然、可读；不要用伪场记、坐标、档案号或重复标签制造设计感。
