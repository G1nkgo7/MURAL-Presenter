# 正式公共系统

## 党政庄重

- **签名**：象牙纸感、直立宋黑层级和克制红金线建立正式秩序。
- **场景基线**：事实、政策层级、组织关系和行动要求优先；装饰不得影响权威与可读性。
- **画布**：浅暖象牙或有明确用途的深红峰值页；深浅转换要有章节承接。
- **颜色**：丹朱/正红为主，金色只用于点睛和细线，正文保持松烟墨。
- **字体**：直立中文衬线标题、无衬线正文；不使用斜切、可爱或难辨草书。
- **图片**：真实机构、人物、地点和事件按任务需要使用；标志性徽章必须来自正式素材。
- **图形与图表**：细线、稳定对齐、单红高亮；关系图说明真实组织或政策逻辑。
- **特殊页**：可以居中对称，也可用图文分屏；封面、章节页和结尾页保持红金线、字体角色和图片处理亲缘。
- **avoid**：满页红金、廉价渐变、伪印章、虚构徽章、过度发光和娱乐化标题。

没有正式标志素材时，使用排印、色场和通用几何建立秩序，不生成可能被误认成真实徽章的图形。
