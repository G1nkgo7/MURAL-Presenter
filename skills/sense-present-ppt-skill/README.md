# SensePresent PPT runtime subset

This directory vendors only the MIT-licensed PPT runtime subset required by
the optional `sense-present-ppt-skill` WebUI profile. The bundled entry,
story, tools, and standard-rendering skills are kept together so the profile
can be validated without copying generated examples, browser caches, or the
full upstream skill collection into this repository.

See [`LICENSE`](LICENSE) for the upstream license.
