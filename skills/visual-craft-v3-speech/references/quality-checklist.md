# 质量检查清单(单页 + 整套)

幻灯片质量的**统一判据**,两级:

- **单页检查** —— 一页能否清楚表达、稳定专业。**slide subagent 自检** 与 **review subagent 逐页复核** 都用这套。
- **整套检查** —— 整份能否围绕目标顺畅讲完、多页风格统一。**review subagent 横扫全套** 用这套。

通用优先级:**先硬后软**——能直接毁掉一页的「硬伤」(见单页·维度3)必须先清零,再谈层级 / 美感这类「软伤」。

## 目录

- 一、单页检查:表达与内容逻辑、版式组织与阅读路径、可读性与技术完成度、视觉元素与风格适配
- 二、整套检查:目标场景、全篇结构、视觉系统一致性、整套美学气质、展示风险
- 三、可机核 lint 项:可由脚本直接扫出的 anti-slop / 技术硬伤
- 怎么用:slide subagent 与 review subagent 的分工

---

## 一、单页检查

一页要同时立得住:**内容讲得清 + 视觉撑得住**。

### 1. 表达与内容逻辑
- 主题 / 重点 / 结论清楚;**标题与正文指向同一表达目标**(不跑题、不各说各的)。
- 论证信息**支撑页面主旨**(数据 / 论据服务于这页要说的那一件事)。
- **完成当前页型任务 + 必含要素**(案例页有具体案例、介绍类有代表作品、数据页有真实 / 标注数据、方案页有具体做法……见 SKILL.md 页型词表后的清单)。〔页型名按 deck 语言可能是中文或英文 role(结束页=Closing、案例页=Case Study 等),按**页型语义**认,别因字面语言不同而漏判。〕
- **文本与规划一致**:上屏文字就是规划里的文案(未被改写 / 扩写 / 编造);**无规划外内容**(自创页眉 / 水印 / 「机密·内部使用」标识 / 日期 / 多余装饰文字;但 base.css 自带的 `.slide-footer` + `.page-no` 不算自创)。
- **标点全 / 半角跟着语言走(全 deck 一致)**:中文段落用全角(`，。：；！？「」`)、英文用半角,**一句里不中英混标点**;数字 / 代码 / 日期 / 百分比 / 缩写等半角语境例外。**扫到中文字后紧跟半角 `,` `.` `:` `;` = 不合格**(如 `间,` `来源:` `径;`)。
- 内容本身无逻辑问题(因果 / 顺序 / 归类不自相矛盾)。**事实准确性**:每条上屏事实能追溯到对应页 `speech.md` 的参考资料、或已标"示意 / 待核";涉及具体人 / 作品无明显错误(性别 / 称谓 / 归属)。〔注:准确性的**唯一关口是编排器**——research→编排器抄进规划这一跳;slide/review 都看不到 research 原文,抄错下游发现不了,所以编排器抄写时必须回 `research_NN.md` 逐项核对。〕
- **来源不上屏**:`research_NN` / `materials` / `plan` / URL / 来源编号 / 参考资料列表都不出现在页面文字中。真实外部出处写入逐页规划的 `## 来源`,由脚本汇总到 `speech.md` 的“不朗读”区；示意数据仍在页面本身标「示意 / 自拟」。

### 2. 版式组织与阅读路径
- 有**明确视觉中心**,主次层级清楚(一眼知道先看哪)。
- 排版稳定美观(对齐、网格、留白均衡,不挤不空)。
- **观看顺序顺畅**(视线自然流动,不跳来跳去)。
- 装饰**不干扰阅读**(纹理 / 形状 / 图标是辅助,不抢内容)。

### 3. 可读性与技术完成度
- 关键信息清楚可读(字号够大、对比够、不被压盖)。
- **最小字号 ≥ `--fs-min`**(投影场景可读);没有为塞内容把字缩到看不清。
- 表达元素**完整呈现**,能读出主要含义(图表有轴 / 图例 / 标签,不是半截)。
- 导出质量清晰稳定(不糊、不截半截)。
- 画面无缺陷。

> **本维度的「硬伤」——必须先清零(slide subagent 自检红线):**
> ① 溢出 / 出框(**内容**——文字 / 图表 / 卡片——越过 1600×900 或容器边)。注意:`.slide` 是 `overflow:hidden`,溢出会被**静默裁掉**而非露白条黑条,所以要**主动核对**页脚 / 页码 / 正文首末行 / 图表轴标签是否完整,别等"看到出血"。**渲染门:`render.py` 的 stdout 有 `⚠ OVERFLOW: …` 就是机检出的越界元素清单(比人眼可靠——因为被裁的看不见),命中即修**;**同门还打 `⚠ OVERLAP`(两文字块相互遮盖)、`⚠ CROWDED`(文字在定高节点 / 表格格里塞不下被切)、`⚠ TEXT-OVERFLOW-BOX`(内容盒 overflow:visible、文字撑出文本框但没被裁也没超整页——CROWDED/OVERFLOW 之间的盲区)、`⚠ INNER-GAP`(卡片中间空一大块:margin-top:auto / 等高网格把内容少的卡拉高)、`⚠ FOOTER-PUSHED`(正文体量把页脚顶下去/压过页脚顶/挤出视口——最严重的底部溢出)、`⚠ WIDOW-LINE`(文本末行 1-2 孤字)、`⚠ IMG-LONELY`(位图/照片过小且孤立)、`⚠ COVER-OOB`(封面标题贴到/越出安全区)、`⚠ FOOTER-COVER`(媒体/装饰碰页脚)、`⚠ DECOR-OVERLAP`(装饰压文字),同样命中即修**,别放行。〔满铺背景图用 `.slide--bleed` 是合规的,不算出框。〕
> ② 遮挡(文字 / 图表 / 图片 / 形状互相压盖),尤其页脚/页码被底图或装饰压住;
> ③ 占位残留(空框、占位文字、缺轴 / 图例 / 标签的半截图表);
> ④ 破图破表(`<img>` 或 ECharts 没真正渲染出来);
> ⑤ 中文豆腐块(□□□,字体没加载);
> ⑥ 可读性不足(文字对比太低看不清);
> ⑦ SVG / 概念图硬伤:图被缩成孤立小块 / 窄条,正文区大片死白;标签互撞 / 贴线 / 被连线压住;节点框内 padding 不足。`⚠ SVG-SMALL` / `⚠ SVG-LABEL-OVERLAP` 命中即修;
> ⑧ 配色出界(调色板外的红 / 粉 / 绿、ECharts 默认色、多系列没用 `--series-*` token、涨跌只靠色相而无 ↑↓/正负号、或涨色 = 警示色)——一律换回 base.css 的 token + 双通道。

### 4. 视觉元素与风格适配
- 各元素**协调**(配色 / 字体 / 图形语言一致)。
- 元素间有清楚层次,**视觉服务内容重点**(强调的是关键信息,不是装饰)。
- 视觉风格**贴合 deck 选定的 风格 / 色调 / 主色**(见 base.css 与 plan/deck.md)。
- **素材用得准**:无多余素材(每张图都承载内容);未被严重裁切毁主体、未拉伸变形、比例匹配槽位(对不上用 `contain` 而非大裁)。
- 无**低质**效果(**无主题的**廉价渐变 / 滥用阴影毛玻璃 / 千篇一律的 AI 味套版;有主题色彩故事的渐变不算)。
- **层级自信**:标题明显大过正文(标题 ≥ ~2.1× 正文、小标题 ≥ ~1.45× 正文),密页上标题 / 正文 / 标签**不挤成一个字号档**;一眼能分出先看哪。
- **强调有主次**:accent 点在**真正要喊的几处**(不是标题线 / 眉签 / 要点 / 数字全染);单 accent 或主 + 次双 accent 由设计决策;正文 / 分隔线 / 标签用中性墨色浓淡。
- **别用 AI 默认色**:主色来自主题,不是顺手套"深藏青 + 霓虹青/电光蓝"默认科技色或 `#6366f1` 靛蓝(主题真要则有意声明);暗底有色温,accent 不刺眼(降饱和)。
- **面板有体积**:卡片 / 面板靠色调分层(页底→面板→内元素三级),不是扁平深色盒子;没有标题后那团泛用径向"光晕"假景深。
- **对齐**:同一页文字块**对齐到同一条网格线**,没有"居中块 + 左对齐块"两套对齐混用;长标题 / 长句的折行不是忽长忽短的烂 rag。**元素块之间也要对齐**(相邻卡片 / 面板 / 分区的边、内部行槽对齐到同一栅格),别块与块之间各飘各的。
- **同权重同款式**:同一层级 / 重要性的信息(并列小标题、并列数据项、同类标签 / 序号)用同一颜色 / 字体 / 字号 / 标号写法;变款式只为表达强调差异、且**变色 / 变号跟内容含义挂钩**,不是无逻辑地这块蓝那块橙。
- **色块 & 装饰收敛**:成块颜色**尽量** ~3 内(参考、非硬数)、改色有逻辑、同类块同底色;无逻辑多色块(米 / 蓝 / 绿乱拼)= 乱。**克制 / 严谨型 deck**(学术 / 科研 / 报告 / 法律 / 政务)额外:字体收到 2–3 种(别 4–5 种混排)、**无装饰性印章 / 徽标 / 多余母题**——严谨靠秩序 + 留白 + 层级,不靠点缀。
- **标题跨页同锚点**:这页 `.slide-title` 的位置 / 字号 / 字体与其它内容页一致(没被改大 / 挪位 / 折行顶高);英文双语副题「要么都有要么都没有」。
- **数字 + 单位**:大数字的单位(亿 / % / 美元 / ×)是**小一号、退一步**(≈0.5× 数字、不抢戏),不是和数字一样大顶在一起;同一指标族单位 / 精度 / 千分位写法一致。
- **一排卡片对齐**:同一行的卡片**等高、内部各行(数字/标题/正文/脚注)落在同一条基线**,不是有的卡片矮一截、脚注高低参差。
- **卡内留白不过多**(见 design-rules §9⑩⑰):卡片 / 框内容量与框高匹配,没有"一卡挤满、一卡半空"(内容少的卡撑出大片空 = 补内容 / 按最短定高 / 少量内容居中);卡内「正文↔脚注」分隔线只在真有分区时画,别让线悬在空中(§9⑬);**别用 `margin-top:auto` 在等高卡里裂出中缝**(`⚠ INNER-GAP`),别用 `repeat(N,1fr)` 硬撑不等量文本导致溢出(`⚠ TEXT-OVERFLOW-BOX`)。
- **无不必要换行 / 寡行**(见 design-rules §9⑪):一行排得下的短语没被手动 `<br>` 断开;末行没有 1–2 字孤字(「满格」「幕」「风险」甩到下一行);容器没窄到把一句话逼成多行 + 孤字。
- **大标题不挤**(见 design-rules §9⑫):粗宋 / 得意黑等粗重字做大标题时,标题一行舒适排下、字有呼吸;标题过长时已降字号,而非硬撑满屏粗字;粗中文大字没叠负字距。
- **序号 / 大字与右侧标题顶端对齐**(见 design-rules §9⑯):大号序号(01/02…)与右侧小号标题**顶端齐平**,不是序号顶比标题顶低(错位根因 = 用了 `align-items:baseline` 或序号 `line-height:1`);页面内联重写 arch-index 时也守这条,别照抄 baseline。
- **封面 / 文字块重心不偏上**(见 design-rules §9⑭):封面 / hero / 过渡页文字块视觉居中或有意构图位,没把标题贴顶、下方留一大片无理由空白。

## 二、整套检查

全套要能**围绕目标顺畅讲完**,且**多页之间风格统一**。

### 1. 目标场景
- 适配**汇报场景 / 展示对象**(受众、媒介、正式度都对得上)。
- 有 `plan/design-brief.md`,且设计契约说清**受众 / 场合 / 材料质地 / 视觉媒介 / 参考取用 / 禁区**;成品看得出这些判断被执行。

### 2. 全篇结构与跨页推进
- 整体结构**清晰、完整、有效**(封面 → 铺垫 → 论证 → 总结 / 行动 → **结束页 / Closing(封底,必有)**,叙事弧线完整)。
- 相邻页**自然承接**(不断层、不重复、不突兀跳跃)。
- **长 deck(≥8 页)分了"幕"**:有 2–4 个章节、**每幕前有过渡页**(不是一长串等权内容页平铺);封面列的目录板块都成了过渡页、顺序一致。**所有过渡页 / 章节分隔页版式、结构、字体、背景手法全套统一**(同一模板、只换章节名 + 序号)——出现「几个过渡页字体 / 版式 / 结构各不同」= 不合格。
- **是"搭建"不是"清单"**:有一个统领论点、每页回扣它(不是每页换个指标重说"很大");没有两页讲同一宏观点没合并。
- **密度有节奏**:没有满密页背靠背、也没有极简页背靠背;任一页信息点 ≤3。

### 3. 视觉系统一致性
- 页面元素**多页之间保持统一**(配色 / 字体 / 页眉页脚 / 页码 / 间距同一套 token)。
- **固定框架全套一致**:标题位置 / 页脚 / 页码 / 安全边距套同一 base.css 骨架,没有逐页漂移(标题忽大忽小、装饰线乱动、重心忽上忽下)。
- **素材视觉配方统一**(同媒介 + 同调色 / 处理,不风格色调乱飞):图标 / 图片 / 图表 / 形状用**同一种视觉语言**,别扁平 + 3D + 手绘 + 照片质感**混杂**——一个 deck 一种素材调性。底图 / 背景图不用低劣素材(噪点 / 低分辨率 / 拉伸变形 / 带外来水印)。
- **同类页型有稳定表达**(所有数据页一个调性、所有对比页一个结构)。
- 页间**视觉复杂度 / 信息密度 / 设计精度相对均衡**(不忽繁忽简、忽精忽糙)。
- 无个别页明显低质拖后腿。

### 4. 版面填充率 / 构图密度(★原质量门缺的轴,补上)
- **每页「填满」判据**:一页技术全干净(无溢出 / 豆腐块 / 遮挡)但**构图发空、读成「空 / 没做完」= 不合格**——差别全在字阶 / 锚定视觉 / 密度。`render.py ⚠ SPARSE`(填充率 <42%)命中必处理;这类多是**规划 / base.css 定死**,别指望子代理临场救。
- **低条目页(目录 / 3-条页)要撑满**:别靠 `justify-content:center` 把少量内容居中、上下留大条空;放大标题 / 序号字阶、条目做成撑满纵向的编号块、加锚定视觉。真只有 2–3 条 → 合并轻页或每条升维(加释义 / 数据 / 图元)。
- **禁行内 leader gap**:`auto 1fr auto`(标题左 + 英文右)让 1fr 段空着、中段大片空 = 不合格——加引导线 / 点划把左右连成一体、或拉近、或让内容占满该列。
- **纯装饰英文别喧宾夺主**:CONCEPT / ACTION 类装饰英文占显眼位、把真信息(「是什么 / 怎么办」)挤到边缘 = 主次颠倒、不合格;真信息更近更重,装饰英文弱化或去掉。

### 5. 整套美学气质(「好不好看 / 协不协调」的整体轴)
- **背景不丑不跑调**:满幅氛围图 busy / 低对比 / 浑浊 / 跑调 = 不合格——宁可干净纯底;**全册一套背景配方**,别每页各生各图导致**各布局类型乱晃**。
- **对比 / 配色纪律(管到装饰元素)**:圆环 / 线 / 英文 / 母题也要够对比——maroon 叠近黑看不清、低对比 gold = 不合格;一页色块 ≤3、accent 只点一处;**禁 glow / 径向渐变假景深**。
- **庄重题材不长成 keynote**:党政 / 政务 / 学术用近黑暗底 + 斜切大字 + 戏剧氛围图 = 调性错(见 `design-rules.md` §1 党政条 / §2 字体条),该换**直立衬线(思源宋体)+ 克制红金 + 干净底**。

### 4. 整套美学气质 + 美术指导(治"模板味")
- 全套形成**一致的视觉气质**(像一个人做的一整套,不是拼盘)。
- 视觉语言**匹配主题与媒介**。
- **有设计概念,不是模板填空**:这套 deck 看得出一个**贴主题的设计概念 / 色彩故事**(写在 `plan/design-brief.md` 与 `plan/deck.md`),不是"换个色的通用 AI deck"。
- **参考已被转译**:字体、版式、色彩、母题像是从本 case 的材料 / 受众 / 场合长出来,而不是把 `design-styles.md` 的成套配方或 `layout-patterns.md` 的原型原样照搬。若一眼像通用 recipe 换皮,列为 should_fix。
- **版式不单调**:**不是每页都"眉签→大标题→一排卡片"**——等权卡片/宫格全套 ≤2 页、2×2 田字格 ≤1 次,其余页用了不同版式族;相邻页不雷同。
- **有破格 hero 页**:全套至少 1 页在叙事高点**打破栅格**(特大数字/词、满幅金句、或 >70% 主图/图表),和其它页明显不同。
- **母题贯穿**:封面的视觉母题在 ≥3 个内页以变体复现,不是封面用一次就丢。
- **图表是新闻图**:数据页标题写**结论**(发现句)不写题目;图直接标值、砍冗余轴/图例;KPI 一排里只有一个当头条。

### 5. 整体展示风险
- 没有**大量页面反复出现同类问题**(同一毛病系统性复发 → 多半是 base.css / 规划层的根因,应改设计系统而非逐页修)。
- 无**缺页 / 重复页 / 顺序错误 / 章节标题与内容不匹配**。
- **最后一页必须是「结束页 / Closing」(封底式收束),且与前一页(总结 / 行动)版式明显不同**(不是又一张内容页);不含任何"感谢聆听 / 感谢阅读 / 感谢观看 / Thank you for listening / watching / reading"之类收尾套话(中英都禁,硬约束)。

## 三、可机核 lint 项(machine-checkable)

这些判据**能直接数出来 / 正则核 / 从 token 算**,不靠审美——slide 自检和 review 复核都能机械过一遍。逐条勾:

- [ ] **强调有主次(非到处染)**:accent(主 + 可选次)用在真正要喊的几处、有清晰主次,不是标题线 / 眉签 / 每个 KPI / 每根柱全染(那是「到处强调 = 没重点」);单色还是双 accent 由设计决策、不设死次数(见 `design-rules.md` §1)。
- [ ] **裸 hex 计数(raw-hex)**:`:root`(base.css token 块)**之外**的裸 `#rrggbb` **≤12 个**;多了 = 没走 token,收回 `var()`(派生色用 `color-mix()`)。
- [ ] **P0 anti-slop 零命中**(精确清单见 `design-rules.md` §11「精确 anti-slop 清单」):没把 7 个靛蓝/紫 hex(`#6366f1`/`#4f46e5`/`#4338ca`/`#3730a3`/`#8b5cf6`/`#7c3aed`/`#a855f7`)当**顺手默认** accent(主题有意声明的不算);没有**无主题的**通用信任渐变(紫→蓝 / 蓝→青 / 靛→粉;有主题色彩故事的渐变不算命中);无 emoji 图标(✨🚀🎯⚡🔥💡📈🎨…);无编造指标("10× faster"/"99.9% uptime"/"3× more");无 filler(`lorem ipsum`/`feature one·two·three`/`placeholder text`);无圆角卡+左侧彩条 accent;无外部占位图 CDN(unsplash / placehold.co / picsum…)。
- [ ] **uppercase 字距(all-caps-no-tracking)**:每条 `text-transform:uppercase`(含 inline `style=`)必带 `letter-spacing≥0.06em`(建议 0.08em)。无字距的全大写是头号业余 tell。〔中文别用 `uppercase`。〕
- [ ] **display 负字距**:`≥48px` 的大标题带 `letter-spacing:-0.02em~-0.03em`(松垮的大字同样露怯;拉丁文,中文大标题不做过度负收紧)。
- [ ] **对比度 gate(contrast-gate)**:正文对底 **≥4.5:1**、大字(>18px 或 14px 粗)**≥3:1**(可从 `base.css` 解析出的 token 色值算 WCAG 比,或在渲染图上取色比对)。不达标就把 text 用途换深一档(600 级)。
- [ ] **每张 slide 有明确明度角色 + 明暗节奏(slide-theme / slide-rhythm)**:每页归位到「常规内容底 / 加深过渡底 / 满铺 hero」之一,体例全套统一。⚠️ 本 skill 守「全套一个背景模式」,所以这条**不是让亮↔暗互跳**,而是**在同一模式内用明度变体打断疲劳**——别**连续 3 张**停在完全一样的底;章节点 / 叙事高点用同色系**加深 / 满铺**变体,8+ 页至少 1 张满铺 / hero 打破节奏。
- [ ] **骨架契约(layout-contract)**:`render.py ⚠ CUSTOM-BODY` / `⚠ ABS-LAYOUT` 必须为零;root 直下只用标准 `.slide-title` / `.slide-body` / `.slide-footer`,正文内容不得用 absolute/fixed 拼版。
- [ ] **遮盖护栏(layout-guard)**:`⚠ DECOR-OVERLAP` / `⚠ FOOTER-COVER` 必须为零;装饰层低 z-index 并避让标题/正文/页脚,底部图/半幅图不得压页脚/页码。
- [ ] **SVG 概念图体量(svg-diagram)**:`⚠ SVG-SMALL` / `⚠ SVG-LABEL-OVERLAP` 必须为零;概念图套 `.arch-diagram`/`.diagram-canvas`/`svg.svg-diagram`,占满正文区主要面积,标签字号和节点间距可读。
- [ ] **文本框溢出 / 卡内空洞(box-fit,见 §9⑩⑰)**:`render.py ⚠ TEXT-OVERFLOW-BOX`(文字撑出 panel/卡片/正文区)/ `⚠ INNER-GAP`(卡中间空一大块)必须为零;等分网格(`repeat(N,1fr)`)承载不等量文本改 `auto`+顶排、去掉不必要的 `margin-top:auto`、多区堆叠页不写死 `height:XXXpx`、封面巨字号用 `clamp()`/按字数降档不顶出安全区。
- [ ] **底部溢出(footer-fit,见 §9⑦⑪,最严重)**:`render.py ⚠ FOOTER-PUSHED` 必须为零——正文体量绝不能把页脚顶下去 / 压过页脚顶 / 挤出视口;放不下就减字 / 拆两页 / 换紧凑版式、定高区改 `minmax(0,1fr)`、守 `--body-safe-bottom`。
- [ ] **寡字 / 寡图(orphan,见 §9⑦⑱ / §6)**:`render.py ⚠ WIDOW-LINE`(末行 1-2 孤字)/ `⚠ IMG-LONELY`(位图孤立小图)尽量为零;文字块加宽 / 去多余 max-width 消孤字,位图放大 / 落网格 / 配说明 / 成组消孤图。
- [ ] **封面出界 + 不素(cover,见 §9⑦⑰ / §6)**:`⚠ COVER-OOB` 为零(标题守 `--margin-x/y` 安全边、别堆左上角);封面在主视觉 + 巨标题外有 2–3 个设计层(副题 / 元信息 / 母题 / accent),一眼看得出设计过、不是"一图一字"模板感。
- [ ] **配图形状不单调(shape,见 §6)**:配图不是清一色同尺寸直角方块——按气质用 `.ph-circle/-arch/-angled/-round-lg…` 给恰当形状 / 描边,克制成系列(一页 ≤1-2 种、庄重题材仍克制),主体不被形状裁掉。
- [ ] **对齐 + 间距规整(align,见 §9⑯⑱ / `⚠ VBALANCE`)**:同页元素共对齐轴(共左线 / 顶对齐 / 基线 / 数字右对齐)、间距走 `--space-*` 阶梯且同级等距、重心在安全区居中或撑满;眯眼看没有"歪着 / 空一条 / 参差不齐"的别扭。

〔单背景模式下的"节奏"= 同一模式内靠明度 / 密度变体拉开,而非亮暗背景互跳。〕

## 怎么用(各角色对照)

- **slide subagent**(`subagents/slide.md`):写完渲染后按「单页检查」自检,**硬伤优先清零**,`edit→渲→看` 最多 3 轮。它看不到兄弟页,不负责跨页一致性。
- **review subagent**(`subagents/review.md`):通过全册概览 + 自适应分组联系表覆盖所有页面,同时过「单页检查」与「整套检查」；一次建立问题账本,直接合并修复视觉问题,重渲变化页并用复验联系表看新像素。它是唯一 Review,不再拆分或重派第二个 Review。
- **编排器**:规划期就用「单页检查·表达与内容逻辑」「整套检查·全篇结构」自检叙事与内容(规划期堵掉比渲染后返工便宜)；收尾只接受唯一 Review 的 `ready` 结论,不得覆盖 `blocked` 或另派 Slide/Review 绕过质量门。
